Phaser 4: official coding-agent skills with engine code examples

The Phaser engine repository now provides subsystem skills for agent-assisted development, including scenes, Arcade/Matter physics, input, assets, cameras, animation, UI, and migration. The official README explicitly names several coding agents, and the skills contain practical API examples linked to engine source.

What the source actually contains

Reusable instruction files with JavaScript examples, backed by the engine implementation. Verified skills/physics-arcade/SKILL.md includes player/platform setup, collision registration, keyboard movement, and GameConfig; it points to src/physics/arcade/. Other exact paths include skills/scenes/SKILL.md and skills/v3-to-v4-migration/SKILL.md.

Limitations

Targets Phaser 4; do not silently apply its rendering/migration guidance to Phaser 3 projects. A skill is knowledge and example code, not an editor-control service or a finished game. Agent names come from the official README and are not an end-to-end compatibility certification; Google models being mentioned is not treated as proof of Gemini CLI usage.
