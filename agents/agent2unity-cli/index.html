Agent resource

agent2unity-cli

A .NET command-line client plus a C# Unity editor daemon that lets coding agents create and modify Unity assets through editor APIs and run compilation/test checks.

What the source actually contains

Verified .NET CLI Program.cs, C# HTTP daemon/main-thread dispatcher, serialized-field and prefab/scene commands, and Unity Test Framework command implementations. Agent integration files explicitly cover Claude Code skills, Codex AGENTS.md, Cursor rules, and Gemini CLI GEMINI.md.

Limitations

Requires a running Unity Editor/daemon and .NET SDK 8; tests additionally need Unity Test Framework. The daemon binds to localhost but has no authentication check in the reviewed request path, so any process that can reach the port can invoke editor commands. Keep it local and stop it when unused. It controls documented editor operations, not arbitrary gameplay acceptance; agent instruction files do not establish equal live testing.
