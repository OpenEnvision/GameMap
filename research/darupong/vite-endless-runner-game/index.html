darupong/vite-endless-runner-game

A React Three Fiber/Three.js runner whose inspected source implements lane movement, jumping/sliding, obstacle and coin handling, synthesized audio and a browser-local top-ten leaderboard.

License and rights boundary

No project-wide reuse license was found in the inspected first-party tree or manifests. Public source visibility does not establish permission to redistribute; dependencies and media may have separate terms.

AI attribution boundary

The repository description says the game was built entirely with Claude Code. The inspected deployment-config commit has a Claude Sonnet 4.6 co-author trailer; this is narrower corroboration, not an independent all-code authorship audit.

Qualifications and limitations

  • The inspected leaderboard reads and writes localStorage and retains ten entries; it is a browser-local score list, not an established shared online leaderboard.
  • No README or project-wide license was found. Gameplay, touch usability, audio and performance were not run or tested.
  • Read-only documentation, manifest and bounded static source inspection only; no repository code executed, dependencies installed, game opened, or runtime, gameplay, networking, build or performance behavior verified.
