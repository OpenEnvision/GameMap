Repository research record

snowfrogdev/nanojet

A TypeScript/Vite workspace containing a WebGPU engine and a Pong example. Inspected source connects an ECS world, game loop and renderer, with player/CPU paddles, scoring and synthesized scoring sound in the example.

License and rights boundary

No project-wide reuse license was found in the inspected first-party tree or manifests. Public source visibility does not establish permission to redistribute; dependencies and media may have separate terms.

AI attribution boundary

No explicit AI-development attribution was established from the inspected first-party material; naming, gameplay AI and procedural generation are not authorship evidence.

Qualifications and limitations

  • The inspected renderer explicitly requests WebGPU and throws when no device is available; no fallback was established.
  • A Pong example is present in source. The repository description’s lightweight/js13k goals are not measured bundle-size, performance or broad engine-completeness results.
  • Read-only documentation, manifest and bounded static source inspection only; no repository code executed, dependencies installed, game opened, or runtime, gameplay, networking, build or performance behavior verified.
