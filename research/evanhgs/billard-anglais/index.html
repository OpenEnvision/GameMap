Repository research record

evanhgs/billard-anglais

A carom-style billiards project with a Pygame desktop implementation and Flask/Socket.IO browser routes for local play and two-player rooms. The homepage calls it 3D carom billiards, and the inspected desktop scoring code awards a point after contacting both other balls.

License and rights boundary

No project-wide reuse license was found in the inspected first-party tree or manifests. Public source visibility does not establish permission to redistribute; dependencies and media may have separate terms.

AI attribution boundary

The repository description calls the game vibe-coded but names no model or tool. A branch name containing Claude was not treated as proof of code authorship.

Qualifications and limitations

  • The repository name says English billiards, but its homepage and inspected scoring logic describe carom-style play; do not label it a verified implementation of official English-billiards rules.
  • Online source relays player shots and end-of-turn state; no live synchronization or authoritative-physics behavior was verified.
  • Download routes exist, but release binaries, build success and platform compatibility were not verified.
  • Read-only documentation, manifest and bounded static source inspection only; no repository code executed, dependencies installed, game opened, or runtime, gameplay, networking, build or performance behavior verified.
