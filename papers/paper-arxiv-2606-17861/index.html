Practical use notes

  • The Apache-2.0 benchmark contains tasks, replay tools and model-judged evaluation. The author gallery links 31 selected Godot Web builds; they are examples, not independently reproduced benchmark results. Local benchmark use requires Godot, Harbor/replay dependencies and model credentials.
