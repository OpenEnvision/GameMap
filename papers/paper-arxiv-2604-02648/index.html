Practical use notes

  • The current Apache-2.0 repository is an industrial QA framework with Dark Castle example task packages. Its current hint/reward protocol differs from the paper-era game-bug recall evaluation; the full 30-game paper corpus was not established. Hosted sandbox/model accounts and external software releases are separate requirements.
  • A repository mentioning this paper was found through paper metadata, but author ownership or an official project-to-code link was not established. It is not counted as official source code.
