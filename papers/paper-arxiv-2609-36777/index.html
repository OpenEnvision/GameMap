Practical use notes

  • Author-associated source files and the listed license were inspected. External model accounts, environments, datasets, assets and dependency terms remain separate from the repository license; no model/game was executed in this review.
  • The current repository evaluates a newer 160-task text-to-scene construction release; it should not be treated as the exact source snapshot of the paper-era editing/preservation experiments.
