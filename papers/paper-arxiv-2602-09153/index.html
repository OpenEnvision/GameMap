Usage notes
Project includes interactive pre-generated 3D scene viewers; this is scene inspection, not online text-to-scene inference.

Practical use notes

  • MIT-licensed scene-generation source is released. Default asset generation requires gated SAM model access and approximately 32 GB GPU memory, plus OpenAI credentials and separate scene/asset data. The website viewer is a pre-generated scene inspection demo.
