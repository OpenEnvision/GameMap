Usage notes
Install the Gradio UI extras and obtain Stable Audio Open weights; accepting model terms and sharing contact details are required.

Practical use notes

  • MIT covers stable-audio-tools code; Stable Audio Open weights are separately gated by the model community license and require accepting terms/sharing contact details. The project sample page contains audio recordings, not a hosted generator.
  • The project’s demo page is a static audio-sample gallery, not an interactive model demo.
