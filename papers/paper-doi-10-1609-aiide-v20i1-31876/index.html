Usage notes
The paper links this custom GPT as a rapid mock-up of partial PANGeA features, including dynamic rules and personality-biased NPCs. ChatGPT sign-in/service limits apply; it is not the complete Unity/REST implementation and was not playtested.

Practical use notes

  • The official GitLab tree includes server, prompts, evaluation, web-version and dark-shadows code under an MIT license. Its root README is a generic template, so no documented local-run demo is claimed. The paper’s hosted GPT prototype exposes only partial features.
