  2. Read the creator’s architecture and model disclosure.
  3. Inspect procedural weapons, enemies and audio implementation.
  4. Tune one weapon or enemy and verify a wave and shop transition.

试玩与运行

  • Play Astra Floor

    Desktop WebGL, keyboard and mouse. Wait for INITIALIZING to finish, choose a difficulty, then DEPLOY. WASD moves, mouse aims/fires, R reloads, Q heals, G throws a grenade, and V uses melee. Runs are not saved. The in-app browser could not capture the mouse during review; a normal desktop browser is recommended.

项目源码

  • 查看完整 FPS 游戏项目

    Game implementation, procedural models, bundled textures/music and tests. Node.js 22.13+; npm install then npm run dev. Third-party texture credits are documented separately.
