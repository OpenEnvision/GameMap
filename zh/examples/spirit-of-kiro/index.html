AI 工作流与开发背景

Kiro 官方项目说明超过 95% 的代码通过提示 Kiro 编写。配套指南使用这个实际游戏讲解引导文件、修复、重构、规格、钩子与 MCP；游戏运行时也用 AI 生成物品及合成结果。

研究这个工作流

  1. Read the official setup guide and confirm the AWS model access required for the runtime.
  2. Deploy the Cognito resources, start the client/server stack, and bootstrap the local DynamoDB tables.
  3. Play the discover, craft, and sell loop before attempting the challenge branch.
  4. Follow one guided bug fix or feature change and verify the resulting interaction in the game.
