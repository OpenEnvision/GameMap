Nagi Home：小螃蟹的日常

照顾住在程序化小屋里的螃蟹 Nagi：放食物、扔球、邀请它使用家具，并从日记观察每日需求变化。这个安静的生活模拟器会保存进度。

AI 工作流与开发背景

作者明确说明，代码由 Claude Cowork 中的 Claude Opus 5.5 生成，并另行注明人类负责企划与发布。这里保留实际客户端 Cowork，不将其改写为 Claude Code；作者没有公开完整对话。

研究这个工作流

  1. Place food or throw the ball, then watch Nagi’s activity and diary change.
  2. Read the single index.html to follow daily needs, activity selection, Three.js models and localStorage persistence.
  3. Serve the repository with a static HTTP server or open its HTML in a browser; Three.js and fonts are fetched from external CDNs.
  4. Change one need or activity rule, then check its effect at normal and accelerated time speeds.

试玩与运行

  • 试玩 Nagi Home

    Japanese interface. Drag to orbit, wheel/pinch to zoom; the food and ball buttons trigger interactions. Normal food placement and ball throwing were checked in Chrome, including diary feedback. This is a life simulation without a combat or level-completion goal.

项目源码

  • 查看完整游戏项目

    Complete single-file HTML with procedural Three.js scene, need/activity systems, dialogue and localStorage saves; MIT code. Three.js r169 is loaded from jsDelivr and fonts from Google Fonts, so a clean run requires those network resources. No coding-agent subscription is needed to play.
