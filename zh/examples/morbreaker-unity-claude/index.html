AI 工作流与开发背景

KingMordas 说明几乎整个游戏由 Claude Code 通过 Unity MCP 插件完成，包括玩法脚本、场景与预制体连接、测试及文档。AI 编辑工具与发布游戏的运行环境相互独立。

研究这个工作流

  1. Download the Windows release or serve the published WebGL build over HTTP.
  2. Try paddle steering, acceleration, loss, restart, and the local score list.
  3. Read the creator’s Claude Code disclosure and inspect the gameplay C# scripts.
  4. Open SampleScene.unity with Unity 6000.4.11f1, change one level rule, and test progression.

试玩与运行

  • Download morBreaker for Windows or WebGL

    Version 1.2.0 includes Windows standalone and WebGL ZIPs. Extract the Windows build and launch it, or serve the WebGL build over HTTP. A/D or arrows move, Space launches, H shows scores, and Space/Enter restarts. Pointer/touch controls are included; no public hosted play link is supplied.

项目源码

  • 查看完整 Unity 游戏

    MIT-licensed Assets, Packages, ProjectSettings, scenes, and C# gameplay source. Requires Unity 6000.4.11f1; open Assets/Scenes/SampleScene.unity and press Play. Windows/WebGL build modules are needed only for packaging; Claude/MCP tooling is not required for play.
