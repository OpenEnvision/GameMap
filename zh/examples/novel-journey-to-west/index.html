把三借芭蕉扇篇章改编为中文回合制 RPG，包含彩绘场景行走、任务、装备、宠物和指令战斗。

AI 工作流与开发背景

Zenstory 将该游戏作为 NovelToGame 代理工作流的产物发布，提供原著分析、被淘汰的概念、玩法与美术设计、生成美术、完整实现及 QA 记录。案例没有明确某一个编码客户端，不能从工具支持列表推断所有客户端都参与了制作。

研究这个工作流

  1. Play the village and use the quest tracker to reach an NPC or a battle.
  2. Compare the novel chapter references with the selected fan, transformation and five-element mechanics.
  3. Read the design, art and QA files to distinguish implemented systems from deliberately omitted multiplayer features.
  4. To run locally, serve examples/journey-to-the-west/build/app with python3 -m http.server 5173; inspect the JavaScript battle implementation before changing a rule.
