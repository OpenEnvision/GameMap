Core Business

AI 工作流与开发背景

作者将游戏代码、测试、纹理、翻译、模型和 Blender 生成脚本归于 Claude Opus 5.5，音效与音乐来自 ElevenLabs。该项目使用新资产重新实现 Motherload 风格的规则，并明确定位为非商业实验；未说明具体编码客户端。

研究这个工作流

  1. Start a new game and learn movement, downward drilling, fuel and return-to-surface shops.
  2. Read the fixed-step simulation separately from the Three.js renderer and committed GLB models.
  3. Serve the repository root with a static HTTP server; opening ES modules via file:// does not work.
  4. Change one mineral or upgrade rule, then check drilling, selling, fuel use and save/reload.
