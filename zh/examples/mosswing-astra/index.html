AI 工作流与开发背景

Ayi1337 公开了 Astra 原始提示和单文件 HTML 结果，称其为一次 Xhigh 的单轮测试。人类规定振翅、重力、碰撞和得分规则，并要求原创角色、世界与画风；这是作者陈述，没有完整生成轨迹。

研究这个工作流

  1. Play and identify gravity, flap impulse and scoring.
  2. Read the original prompt alongside the single HTML result.
  3. Inspect the separate source folder before editing.
  4. Change one flight parameter and compare collision and restart behavior.
