AI 工作流与开发背景

Ask an agent to explain the game scenes, then help adapt input, tune enemy waves, or add touch controls. Check each change against the working browser reference.

研究这个工作流

  1. In the official Sandbox, choose Phaser 3.90.0, then play with the arrow keys and Space.
  2. Explore the complete original game and the tutorial’s separate mobile project.
  3. Follow the official Capacitor tutorial for touch input, resizing, and mobile packaging.
  4. Use an agent to make one change, then verify the game on desktop and mobile.
