Minimal Rogue

探索黑白地牢、打碎方块，管理体力和装备，逐层深入 ASCII 风格的肉鸽冒险。游戏提供英文和日文界面。

AI 工作流与开发背景

Hirotaka Adachi 将开发工具归为 Claude Code，音乐归为 SUNO AI，并称作品完全由 AI 制作，但没有给出确切编程模型。公开项目包含渲染器、规则、界面和四首音乐；作者的这一表述不等于没有人工指导的自主开发。

研究这个工作流

  1. 运行网页游戏，选择新游戏与语言，用 Enter 推进开场和教程。
  2. 用方向键探索首个房间，Space 防御，X 打开指令菜单。
  3. 阅读作者的 AI 披露，检查完整 HTML、CSS、JavaScript 和音乐文件。
  4. 通过 HTTP 提供源码目录，修改一项房间或体力规则，检查移动、交互和新一局流程。

试玩与运行

  • Play Minimal Rogue on itch.io

    Browser keyboard game. Enter confirms the opening and tutorial; arrows move, Space defends, and X opens the menu. A short first-floor run verified movement, block-cracking feedback and the command menu. Later floors, saves and a complete run were not tested.

项目源码

  • 查看完整游戏项目

    Complete static HTML/CSS/JavaScript project and four MP3 tracks; serve the root over HTTP without a package install or build step. MIT code license is included; SUNO music is credited without a separate music license. The reviewed public source index references script version 549, while the itch build references 581, so the two releases are not claimed to be byte-identical.
