在程序生成的后室中探索。这是一款第一人称回合制 Roguelike：移动或等待会触发战斗，装备组合与理智值共同影响每次冒险。

AI 工作流与开发背景

Drew Brereton 明确说明游戏代码由 Claude 辅助开发。项目署名进一步指出使用了 Claude Code，并将原创内容与外部着色器、纹理和字体分开列出。

研究这个工作流

  1. Play the interactive tutorial and compare moving, waiting, equipment, and sanity.
  2. Read the creator’s AI disclosure and the project’s separate attribution file.
  3. Import project.godot in Godot 4.6 and inspect the start menu, procedural levels, and turn systems.
  4. Change one equipment or turn rule, then test a complete run and restart.

试玩与运行

  • Play DEEP YELLOW

    In-development browser build plus Windows/Linux downloads. The creator recommends Chrome or a controller; Firefox mouse input has known problems. Includes horror themes and an interactive tutorial.

更多游玩入口

  • GitHub Releases

    Download — Prepared Windows and Linux builds, plus a self-hostable Web export. These are uploaded game builds, separate from automatic source archives. Release files were verified; native builds were not executed.

项目源码

  • 查看完整 Godot 游戏

    Full Godot 4.6 project, scenes, scripts, assets, shaders, and export presets. The itch page lists code MIT and assets CC0, while CREDITS.md still leaves the original-code license undecided and some third-party licenses unspecified; inspect both before reuse.
