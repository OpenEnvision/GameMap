Beach Kitty

以猫为主角的 Phaser 关卡流程，结合跑酷、平台跳跃、射击和其他街机机制，可选生成猫咪美术。

试玩游戏项目源码开发记录

Phaser 3 · React · TypeScript · 浏览器 · 完整项目源码

引擎

Phaser 3 · React · TypeScript

AI 工作流与开发背景

创作者说明使用 Claude Code 与 Google Gemini。公开项目包含进展日志、架构记录、场景与资产；Gemini 还为可选猫咪定制提供能力。

研究这个工作流

  1. Play the campaign and compare how its scenes share one cat character.
  2. Read the progress log alongside the author’s Claude Code and Gemini disclosure.
  3. Inspect the Phaser scenes and React shell to understand their responsibilities.
  4. Run npm install and npm run dev; the core game runs without a Gemini key.
