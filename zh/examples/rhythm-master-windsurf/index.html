AI 工作流与开发背景

Frank Niu 在作者帖子中链接这款游戏，并描述 Claude Sonnet 3.7 网页对话与 Windsurf 配合的流程：先生成初版，在对话中诊断问题，再由 Windsurf 应用修改。这是人工引导的开发案例，没有证据表明使用了 Claude Code 或一次自主运行完成。

研究这个工作流

  1. Download the repository and serve its directory with a local HTTP server, then open rhythm.html.
  2. Choose a track and difficulty, start the game, and use D/F/J/K as notes reach the target zone.
  3. Test combo scoring, Escape pause and the Space special mode before changing timing or difficulty.
  4. Compare the single-file implementation with the creator’s original brief and debugging workflow.
