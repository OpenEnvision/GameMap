Fang the Fox · Game Boy Color

以真正的 Game Boy Color 游戏形式探索浮空岛、挑战首领、解开谜题，体验小狐狸的冒险。可在浏览器模拟器中试玩，也可下载 ROM 在掌机或模拟器中运行。

AI 工作流与开发背景

Austin Ginder 说明由运行 Opus 5.5 的 Claude Code 将自己的浏览器游戏移植为 C。他提供方向并试听改编音乐；公开构建工具让原版与卡带版共享地图、精灵和规则。

研究这个工作流

  1. Start the browser emulator, choose New Game and advance the opening dialogue with X.
  2. Move, interact and inspect the pause map before comparing the cartridge edition with the original browser game.
  3. Read the creator’s porting account and the C implementation under gbc/src/.
  4. Clone the whole repository, then use Node and GBDK-2020 4.5.0 to rebuild through gbc/Makefile; the generator also reads the root JavaScript game data.

试玩与运行

  • 试玩 Game Boy Color 版 Fang the Fox

    Click Start game, focus the emulator, then press Enter/X to start. Arrow keys move, attack and talk; X is A, Z is B, Enter pauses, and Shift shows the area. Hold keys briefly across emulator frames. The page also offers a 256 KB .gbc ROM for compatible emulators or hardware.

更多游玩入口

  • GitHub Releases · GBC

    Download — Game Boy Color ROM and GBC release ZIP. Requires a compatible emulator or cartridge device; the ROM was not executed in this review.

项目源码

  • 打开完整卡带与浏览器项目

    The gbc/ C project, generators, music arrangements and web emulator are public. Download the whole repository: gbc/tools/build.js reads ../js data and sprites. Rebuilding requires Node and GBDK-2020 4.5.0; the ready-made ROM needs neither. Code/pixel art are MIT; music is excluded from that license.
