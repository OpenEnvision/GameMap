AI 工作流与开发背景

仓库说明代码由本地运行的 Qwen 3.8 27B 生成，再由人手工审查、调试与扩展。作者的开发帖子进一步说明使用 Claude Code CLI 作为执行工具，底层模型为 Qwen。

研究这个工作流

  1. Explore the browser world on foot, then try the car, river, and moving bridge.
  2. Read the credits and the author’s account of using a local Qwen model through Claude Code CLI.
  3. Inspect CARTOON.md and the complete index.html plus vendored Three.js dependency.
  4. Serve a local copy over HTTP, change one interaction, and verify movement and collisions.

    Exploration prototype. WASD walks, Shift runs, mouse drag looks, E talks, F enters/exits the car, and Space/C swims up/down. Touch controls included; mobile performance remains limited.

项目源码

  • 查看完整探索游戏项目

    GPL-3.0 source with complete index.html, vendored Three.js, procedural textures, and implementation notes. Run python3 -m http.server 5191 and open localhost:5191/index.html; file:// loading is unsupported. The original author has ended active development. The creator describes an exploration prototype, not a finished campaign; no complete win/loss loop is claimed.
