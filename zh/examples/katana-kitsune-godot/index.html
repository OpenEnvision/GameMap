Katana Kitsune: Prototype

选择狐妖剑士，在等距视角的动作肉鸽中迎战妖怪、管理体力、拾取道具并深入地牢。这个无声原型支持本地多人，当前源码还记录了后续队伍系统。

AI 工作流与开发背景

作者明确列出 Claude Code、GitHub Copilot、GPT Image 2、PixelLab 和 Meshy 等制作工具。仓库记录了 Meshy 绑定动画、Blender 重定向和 PixelOver 精灵导出流程；没有说明确切编程模型或各助手的代码分工。游戏里的 NPC 队友并不是 AI 辅助开发的证据。

研究这个工作流

  1. 打开 itch 原型，选择一名真人玩家，认领键盘并选择服装。
  2. 阅读作者的 AI 披露，以及角色、战斗和精灵制作流程说明。
  3. 在 Godot 4.7 中通过 GL Compatibility 打开 project.godot；工程已包含可运行精灵和游戏场景。
  4. 调整一项战斗或生成参数，检查标题、选角、地牢、受伤和重开的完整衔接。

试玩与运行

  • Play Katana Kitsune on itch.io

    Silent HTML5 prototype with keyboard and gamepad support. Space confirms player/device choices; allow a clear press and release between setup steps. The browser build loaded and reached player/device selection in review; combat and a complete dungeon run were not exercised. The download is large: about 184 MB of game data plus 40 MB of WebAssembly.

项目源码

  • Open the complete Godot game project

    Godot 4.7 project with scenes, GDScript, Dialogic addon and finished sprite assets. The inspected tree contains about 383 MB of files; no top-level game license was found. The upstream Meshy/Blender/PixelOver authoring pipeline is separate, while its finished runtime sprites are committed. The current source contains newer party/asset changes than the reviewed hosted prototype.
