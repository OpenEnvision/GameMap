AI 工作流与开发背景

作者记录 Claude 编写玩法、着色器、视觉特效和 UI，人工引导机制与材质。仓库包含实际 Godot 游戏、生成资产及资产生成脚本。

研究这个工作流

  1. Play the web build and study territory capture, trail hazards, enemy movement, and sector progression.
  2. Follow the creator’s tutorial from prototype through materials, audio, effects, and web export.
  3. Read CLAUDE.md to understand the agent, Godot MCP, Blender review, and asset-generation workflow.
  4. Open game/project.godot in Godot 4.7 and press F5; study the scripts alongside the included models, textures, and audio.

试玩与运行

  • Play TRON: EXONIX

    Creator-hosted Godot web build. Click to enter the grid, press Space to deploy, use the arrow keys to move, and Escape for the menu. A keyboard and a WebGL-capable browser are recommended.

项目源码

  • Open the complete Godot game project

    Includes the Godot project, scripts, shaders, models, textures, audio, and generation scripts. Local play requires Godot 4.7 standard; API access is only needed to regenerate assets.
