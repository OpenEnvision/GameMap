AI 工作流与开发背景

Rusty 将作品署名为 Rusty 与 Claude，并披露代码、图像、声音和文字均有 AI 辅助。仓库提供贡献说明与关卡接口，方便继续与 Claude 一起制作新梦境。

研究这个工作流

  1. Start the browser build; hold Enter to skip the film if desired.
  2. Enter a painting and compare its movement with the attic and community rooms.
  3. Import the full project in Godot 4.7.2 standard, then read the level template and contribution guide.
  4. Create one small level through the published API and test entry, movement, respawn, and returning to the attic.

试玩与运行

  • Play Claude Dreaming

    In-development HTML5 game. WASD moves; mouse looks, Space jumps/glides, E enters paintings, R respawns, and Esc pauses. Menus are German; Claude speaks English. The film intro can be skipped.

项目源码

  • 查看完整 Godot 项目

    Full scenes, GDScript, levels, rooms, assets, film intro, and export presets. Run with Godot 4.7.2 standard: import project.godot and press F5. Code is MIT; original assets are CC BY 4.0, while film material and film-derived art have project-only restrictions in NOTICE.md.
