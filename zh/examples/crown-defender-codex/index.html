试玩与运行

  • Download and run Crown Defender

    Static browser game. Run python3 -m http.server 8010 and open localhost:8010/index.html; choose Играть (Play). Russian interface. WASD/arrows move; semicolon attacks. Mobile joystick/buttons included. Optional two-player mode requires node server/multiplayer-server.mjs.

    Includes game.js, interface, bundled Three.js, runtime textures, requirements and optional WebSocket relay. No build or dependency installation for solo play. MIT code; see ASSET_CREDITS.md.
