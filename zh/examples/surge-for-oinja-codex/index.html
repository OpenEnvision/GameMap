SURGE for Oinja

在两张可互动地图中对抗机械怪潮，组合电气能力形成构筑。攻击自动发动，玩家负责移动、闪避、选择升级和恢复设施。

AI 工作流与开发背景

Olivia 使用 Codex 中的 GPT-6 Astra 实现战斗、能力联动、程序化环境、界面和调试。原创 Oinja 世界、创作方向和试玩反馈由作者提供；作品经过多轮会话和修改。

研究这个工作流

  1. Start a run and try movement, dodging and automatic attacks.
  2. Read the creator’s contribution disclosure.
  3. Inspect combat, progression and map code under src/surge/.
  4. Change one ability combination and check its effect during a new run.

试玩与运行

  • Play SURGE for Oinja

    Desktop WebGL and keyboard. WASD/arrows move, Space dodges, Q releases Sync Burst, and E interacts. Attacks are automatic. English and Chinese; no mobile touch controls.
