研究这个工作流

  1. Download the source and launch the Pygame window with Python 3.12 or newer.
  2. Race a supplied track and compare the player ghost with the unlockable creator ghost.
  3. Read the development disclosure, then inspect movement, lap timing, and replay storage.
  4. Change a track or handling parameter and complete a validation run before saving.

试玩与运行

  • Download and run Vibe Racer

    No hosted browser build. Requires Python 3.12+ and Pygame 2.6.1+. Run uv run -m src.main; alternatively pip install -e . then python -m src.main. Arrow keys drive, R restarts, G toggles the ghost, and B returns to track selection. Source-checked launch steps; not executed.
