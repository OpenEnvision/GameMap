AI 工作流与开发背景

Mizchi 明确使用 Roo Code（原 Roo Cline）和 Claude 3.5 Sonnet，并禁止人工直接改代码。人类提供基于开发经验的设计、逐步指令和架构约束。原文保留了工作方法与限制，这仍是早期原型。

研究这个工作流

  1. Move with WASD, aim with the mouse and hold the mouse button to shoot.
  2. Read the original sequence from rendering and movement through enemy health and attack warnings.
  3. Inspect docs/overview.md, the shared types and combat modules alongside the creator’s discussion of documentation drift.
  4. For local study, install the project dependencies with the documented pnpm setup and run pnpm dev, then change one attack or movement rule.
