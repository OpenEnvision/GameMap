Cloud Crush：用 Gemini CLI 制作消除游戏

在 8×8 棋盘上匹配云服务图标，争夺限时高分并创造特殊 Gemini 宝石。Google 公开完整 Go 游戏及 Gemini CLI 开发教程。

AI 工作流与开发背景

Google 在仓库中将游戏生成归属于 Gemini CLI，官方 codelab 展示人工通过 Plan 模式、引导提示、浏览器适配、测试和子代理组织开发。这是发布方的开发记录，不是独立测量的自主创作比例。

研究这个工作流

  1. Download the devrel-demos repository and enter codelabs/gemini-cli/gemini-cli-match3-golang. Install Go 1.26.2 or newer; the README’s 1.24+ prerequisite is outdated. For native desktop play, run: go run .
  2. Follow the title and player-name prompts. Use arrow keys to move the cursor and Space to select a gem, then an arrow to swap. Mouse/touch input is also implemented. Compare matching, falling tiles, time bonuses, and score behavior with main.go.
  3. For a local browser build, first prepare the files served by the Go server: mkdir -p public/assets; cp assets/* public/assets/; cp index.html public/index.html. The committed public/assets directory is missing source files required by the game, including background.jpg.
  4. Use the WASM helper from the same Go installation as the compiler: cp "$(go env GOROOT)/lib/wasm/wasm_exec.js" public/wasm_exec.js. Then compile: GOOS=js GOARCH=wasm go build -o public/cloud-crush.wasm .
  5. Run the browser server from the same game directory: go run server/main.go. Open http://localhost:8080. Local play does not require Gemini CLI, an API key, a Google Cloud account, or cloud deployment.
  6. Read the official codelab to trace the development prompts. The browser instructions above were checked against source; this review did not install Go or compile the game. Its preview is a publisher-provided gameplay screenshot.
