evanhgs/billard-anglais

A carom-style billiards project with a Pygame desktop implementation and Flask/Socket.IO browser routes for local play and two-player rooms. The homepage calls it 3D carom billiards, and the inspected desktop scoring code awards a point after contacting both other balls.

适用条件与限制

  • Online source relays player shots and end-of-turn state; no live synchronization or authoritative-physics behavior was verified.
  • Download routes exist, but release binaries, build success and platform compatibility were not verified.
