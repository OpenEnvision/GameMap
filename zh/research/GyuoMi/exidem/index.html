GyuoMi/exidem

Stairwell Iliad is a Three.js exploration/puzzle game whose inspected source wires a player, collision octree and item interactions; its ending code includes speech-recognition behavior and an alternate path when the speech helper is unavailable.

许可与使用权

GPL-3.0 is declared in package.json and a GPLv3 LICENSE is present. Media is mixed-license: credits and the key model’s notice identify CC-BY-NC-4.0 content, alongside CC-BY and CC0 assets. Credited soundtrack material has no reuse grant established by this inspection; the code label must not be applied to all bundled media.

AI 归属说明

No explicit AI-development attribution was established from the inspected first-party material; naming, gameplay AI and procedural generation are not authorship evidence.

适用条件与限制

  • The one-line README is supplemented by HTML UI guidance, credits and static implementation. The landing page requests Chromium, audio and microphone for the ending; the inspected ending also has a fallback path, but actual compatibility and permissions were not tested.
  • Bundled media includes a noncommercial model and separately credited soundtrack material; GPL source licensing is not blanket asset clearance.
  • Read-only documentation, manifest and bounded static source inspection only; no repository code executed, dependencies installed, game opened, or runtime, gameplay, networking, build or performance behavior verified.
