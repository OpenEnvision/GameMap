hnprivv/Forge_FPS

A Three.js/Socket.IO browser FPS whose built-in project guide describes solo target practice, four-player rooms, Free for All and Search & Destroy, with weapon and explosive-barrel mechanics. Inspected server source implements rooms and relays gameplay events.

许可与使用权

Root package.json declares ISC, but no standalone project license text was found in the inspected tree. This is a manifest-only license declaration, not verified permission for every bundled model, font, texture or sound.

AI 归属说明

The inspected HEAD commit message explicitly credits Claude Sonnet 4.6 as a co-author. This establishes a repository-authored attribution for that commit, not an independent audit or proof that the whole game was AI-written.

适用条件与限制

  • The in-app guide documents wall openings/windows acting as solid barriers.
  • Server event-relay source was inspected, but multiplayer behavior, validation/security, physics and the advertised room limit were not tested.
  • ISC is declared only in package metadata; bundled asset rights remain unestablished.
  • Read-only documentation, manifest and bounded static source inspection only; no repository code executed, dependencies installed, game opened, or runtime, gameplay, networking, build or performance behavior verified.
