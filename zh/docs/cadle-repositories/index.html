Reading the status

  • existing: related coverage already exists in GameMap; the row links it rather than creating a duplicate card
  • new-research: newly documented source material; inclusion is not a reproduction or production-readiness endorsement
  • qualified: useful source material with material scope, maturity, licensing, identity or access qualifications
  • unavailable: the requested location could not be inspected; this does not prove deletion or global inaccessibility

Check code, asset, and service terms separately before adapting a project. For changing repositories, use the recorded README revision to identify the inspected material.

Highest-value corrections

  • Cadle and World of ClaudeCraft distinguish code licenses from restricted media or branding. Public repository visibility is not blanket asset redistribution permission.
  • Kaetram documents an unsupported legacy public version, a newer closed-source game, and additional Omnia terms restricting AI-related use. Grove and VOLTMARCH also carry restrictive or proprietary terms; their research value does not make them permissive starters.
  • Chessmata and postprocessing have verified current owner changes. Separately located Miniplex/nengi alternatives must not be represented as authenticated redirects where that relationship was not established.
  • Redblock README and license text disagree; the more restrictive license-file evidence is preserved rather than reporting unconditional MIT reuse. GodotMaker and several shooter projects likewise require purpose-specific terms review.
  • Historical category labels do not prove AI authorship, complete gameplay or even that a project is a game. The rows distinguish frameworks, viewers, services, incomplete scaffolds, runtime agent interfaces and author-disclosed AI development.
  • Unavailable repositories and thin placeholders remain explicit rows. Forks and existing GameMap coverage are retained as relationships rather than silently dropped or counted as independent implementations.
  • Follow-up inspection of pinned nested guides, manifests and bounded source files resolves eight formerly metadata-only entries. Their gameplay/networking descriptions remain static source observations; the Rust placeholder remains metadata-only. Manifest license labels are scoped to the identified package, and exidem’s mixed media includes noncommercial terms.
  • All eight unavailable requested locations remain unavailable.
