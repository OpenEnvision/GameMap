MiniGrid / BabyAI

包含钥匙、门、物体和部分观察的小型导航与语言落地任务，适合作为可重复规划测试的初始基线。

测试目标

  • 代码修改与自动试玩
  • 视觉、控制与规划

适用方向

  • 2D

技术栈

Python · Gymnasium · discrete grid worlds

代码许可

Apache-2.0 in the current repository.

资产许可

Use bundled procedural grid rendering; added images and datasets need their own provenance.

AI 使用与评估条件

Built for agent research. Preserve license notices; explicitly separate rendered pixels, symbolic observations and mission text in each evaluation.

可以尝试的任务

  • Compare seeded door-and-key success rates with a fixed action budget.
  • Modify an environment rule, then check reset, observations and goal completion.
  • Test BabyAI instructions while withholding hidden map state.

配置步骤

  1. Create a Python 3.11+ environment on Linux or macOS and run pip install minigrid.
  2. Import minigrid and gymnasium; create MiniGrid-Empty-8x8-v0 and call reset(seed=0).
  3. Use RGBImgPartialObsWrapper for agent-view RGB; RGBImgObsWrapper reveals the full grid. Record the wrapper, mission-text access, actions, terminated and truncated separately.

使用限制

Source reviewed, not installed here. Windows is not officially supported; default compact observations are not ordinary RGB screenshots.
