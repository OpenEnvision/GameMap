Unity ML-Agents

官方工具与示例场景，覆盖物理、视觉控制、合作与竞争，可将自定义 Unity 场景接入 Python 策略和自动化测试。

测试目标

  • 代码修改与自动试玩
  • 视觉、控制与规划
  • 资产与动画流程

适用方向

  • 2D
  • 3D

技术栈

Unity · C# · Python · sensors and agent actions

代码许可

Apache-2.0 for the toolkit, with third-party notices.

资产许可

Check bundled notices and any added scene assets. The Unity editor and external store assets have separate terms.

AI 使用与评估条件

The toolkit supports agent research and automated testing; its Apache license does not replace editor or third-party asset terms.

可以尝试的任务

  • Compare physics-task success with fixed observations, decisions and reset rules.
  • Change a C# agent or scene and verify sensors, rewards and episode termination.
  • Import a replacement rig or collider and check control stability and visual observations.

配置步骤

  1. Select a release tag, install its supported Unity editor and open the included Project.
  2. Install the matching com.unity.ml-agents package and Python environment package versions.
  3. Open an example scene and connect a policy; route actions by behavior and agent_id, and read both DecisionSteps and TerminalSteps. Python step advances to the next decision, not necessarily one physics frame.

使用限制

Source reviewed, not run here. Editor eligibility, platform builds and version compatibility need local checks. The develop branch is not a stable evaluation baseline.
