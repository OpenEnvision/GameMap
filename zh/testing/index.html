配置、许可与使用限制

A useful open-license baseline for code editing and automated playtests. Record licenses of any additional assets or plugins rather than treating the demo license as a grant for unrelated data.

可以尝试的任务

  • Change one movement or collision rule and verify the original scene still starts and completes its objective.
  • Import a known model or animation, then compare material loading, scale, skeleton mapping and exported behavior.

开始使用

代码： MIT; retain the repository license and notices.

资产： Repository MIT license applies unless an individual demo or bundled resource states otherwise; keep local attribution notices.

Not installed or run in this research pass. Hosted web demos redeploy from master on every commit, so their URLs are not immutable baselines. Pin a compatible source commit for repeatable tests; the development branch and web renderer can differ from stable desktop behavior.
