The Battle for Wesnoth

回合制战术游戏，提供可编辑场景与脚本，适合测试寻路、战术决策、对话和规则修改。

测试目标

  • 代码修改与自动试玩
  • 视觉、控制与规划

适用方向

  • 2D

技术栈

C++ / Lua / Wesnoth Markup Language

代码许可

GPLv2 or later, with component-specific notices.

资产许可

Core artwork/audio uses GPLv2-or-later or CC BY-SA 4.0; copyrights.csv records file-level notices. Add-on artwork/audio may also use Creative Commons NC or ND terms, so audit each add-on separately.

AI 使用与评估条件

Scenarios and scripts provide inspectable tasks, but add-ons and artwork require their own attribution records. Do not assume the engine license covers every downloaded add-on.

可以尝试的任务

  • Create or repair a small scenario with explicit victory and defeat conditions.
  • Measure tactical success, movement efficiency and resource use from a fixed scenario state.
  • Modify a unit ability or dialogue trigger and verify replays and scenario progression.

配置步骤

  1. Install a stable release and select one small scenario with fixed map, units and difficulty.
  2. Use the documented WML/Lua add-on structure for isolated changes.
  3. Record seeds where available and preserve the starting save to control combat variation.

使用限制

Not installed or run in this research pass. Combat randomness and campaign variation require controlled seeds or repeated trials; the normal UI is not a ready-made agent API.
