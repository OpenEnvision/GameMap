Luanti + Minetest Game

可编辑体素沙盒，支持第一人称导航、挖掘、放置、合成，以及 Lua 实体、纹理和世界修改。

测试目标

  • 代码修改与自动试玩
  • 视觉、控制与规划
  • 资产与动画流程

适用方向

  • 3D

技术栈

C++ Luanti engine / Lua games and mods / voxel worlds

代码许可

Luanti engine LGPL2.1 or later; Minetest Game code uses LGPL2.1, with mod-level notices.

资产许可

Minetest Game media defaults to CC BY-SA 3.0; inspect each mod README for authors and exceptions. Other ContentDB packages have independent terms.

AI 使用与评估条件

Lua mods are practical instrumentation points. Record the license of every game/mod and asset added to the world; ContentDB availability alone is not a blanket data-use permission.

可以尝试的任务

  • Create a Lua mod with a fixed navigation, placement or crafting objective and a success signal.
  • Evaluate a first-person agent from the same seed, spawn, inventory and world snapshot.
  • Add an entity or texture and verify coordinate scale, materials, collision and save persistence.

配置步骤

  1. Pin the Luanti release and exact Minetest Game commit or package revision; the game uses rolling releases and is in maintenance-only mode. Create a dedicated local test world.
  2. Save the seed and a pristine world snapshot, then install only the required mods.
  3. Use a small custom Lua mod to expose resets, task state and measurable success.

使用限制

Not installed or run in this research pass. Minetest Game is a basic sandbox without a single built-in benchmark goal; custom task design and a controller bridge are required.
