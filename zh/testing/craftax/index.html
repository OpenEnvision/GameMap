Craftax

支持向量化模拟的生存与合成环境，适合较长动作依赖，以及像素策略与符号策略的比较。

  • 代码修改与自动试玩
  • 视觉、控制与规划

适用方向

  • 2D

技术栈

Python · JAX · gymnax-style API

AI 使用与评估条件

Fix observation mode, PRNG keys, episode handling and package version. Version changes affect comparability: 1.5.0 fixes first-planted-plant growth, and 1.6.0 fixes Craftax-Classic death rewards.

可以尝试的任务

  • Compare survival and crafting progress using identical seeded worlds.
  • Separate image-only policies from symbolic-state policies.
  • Modify a block or recipe, invalidate texture caches when necessary, and check reset behavior.

配置步骤

  1. Run pip install craftax in an isolated Python environment.
  2. Run play_craftax or play_craftax_classic for manual play.
  3. Select Craftax-Pixels-v1 or Craftax-Symbolic-v1 explicitly; keep full Craftax and Craftax-Classic separate. Supply distinct JAX keys to reset and step, and record the auto_reset setting.

使用限制

Source reviewed, not run here. JIT startup is slow. With auto_reset=True, a done step returns the next episode observation/state alongside the previous episode reward/done/info. With auto_reset=False, handle termination before stepping again.
