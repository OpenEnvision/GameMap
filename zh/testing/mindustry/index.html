Mindustry

物流与防御游戏，可在实际项目中研究生产链、建造、资源规划和客户端与服务端改动。

测试目标

  • 代码修改与自动试玩
  • 视觉、控制与规划

适用方向

  • 2D

技术栈

Java / Gradle / factory and tower defense

代码许可

GPLv3; retain notices for dependencies and distributed modifications.

资产许可

Check repository and bundled third-party notices for the selected release; no blanket CC0 asset grant is asserted here.

AI 使用与评估条件

A useful source-accessible test bed for planning and code changes. Retain license records for extracted assets, maps and plugins rather than inferring unrestricted dataset use from the free download.

可以尝试的任务

  • Build a production chain that sustains a specified resource rate before a fixed wave.
  • Change a block or unit rule and verify loading, construction and client/server behavior.
  • Measure resource waste, survival and goal completion on a fixed custom map.

配置步骤

  1. Download the free desktop release or server from an official source and pin the version.
  2. Use a small custom map with fixed starting resources and wave settings.
  3. For source changes, follow the repository JDK/Gradle requirements rather than assuming a preinstalled Java version.

使用限制

Not installed or run in this research pass. Campaign maps and live servers introduce uncontrolled state; use a dedicated map or local server for comparison.
