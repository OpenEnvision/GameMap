OpenTTD

交通运输模拟，适合路线与铁路建设、经济规划、寻路、存档和多人同步测试。

测试目标

  • 代码修改与自动试玩
  • 视觉、控制与规划

适用方向

  • 2D

技术栈

C++ / isometric transport simulation

代码许可

GPLv2; component notices remain applicable.

资产许可

Use the separate OpenGFX, OpenSFX and OpenMSX base sets and retain their licenses. Original Transport Tycoon Deluxe data is not an open asset pack.

AI 使用与评估条件

Open source and open base sets can support reproducible scenarios. Keep the base-set and NewGRF licenses separate, especially when exporting visual fixtures or distributing a benchmark bundle.

可以尝试的任务

  • Connect fixed industries and reach a target delivery or profit level within a fixed game period.
  • Repair a rail deadlock or pathfinding rule and replay the same saved game.
  • Verify save/load and synchronization after a source or script change.

配置步骤

  1. Download the free official-site release and install the open graphics, sound and music base sets.
  2. Fix the map seed, game options, date and starting save; omit uncontrolled NewGRF additions.
  3. Use a small scenario or local dedicated server and define a measurable transport objective.

使用限制

Not installed or run in this research pass. Steam is no longer a zero-price acquisition route for new users. Long simulation horizons need a fixed time budget and consistent simulation settings.
