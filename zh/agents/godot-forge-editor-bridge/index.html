Godot Forge · 实时编辑器与运行时桥接（Tann2019）

MCP 服务与 Godot 插件，支持写脚本、构建可编辑场景、读取诊断、运行游戏、模拟输入，并用保存的情景检查机制。

源码提供的内容

Reviewed script creation/edit/validation/attachment handlers, the runtime command forwarder, and the companion skill. The tree includes a TypeScript MCP bridge, GDScript editor/runtime handlers, and a platformer with a coin-collection test scenario.

使用限制

Requires Godot 4.4+ and Node 20+. Live authoring uses the editor add-on; runtime inspection and input need a running game with the debugger connection. Documentation, tests, and export also have separate headless paths. Code review confirms implemented paths, not successful execution of every operation. This is separate from Coding-Solo/godot-mcp and gregario/godot-forge.
