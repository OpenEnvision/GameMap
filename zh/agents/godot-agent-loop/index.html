实现代码与使用说明

源码提供的内容

Verified TypeScript server/editor bridge, addons/godot_agent_loop/plugin.gd, runtime verification code, cold-model evaluation runners, and an executable launch-demo project. One portable agent bundle exposes build/debug/verify/ship skills and explicit Claude Code, Codex, OpenCode, and Pi adapters.

使用限制

Requires Godot 4.7+ and Node 22+. The default core tool surface uses godot_catalog and godot_call to reach unlisted tools. Filesystem access is denied without configured roots unless explicitly overridden; runtime reflection and code-execution groups are disabled by default. Those RPC gates do not sandbox project GDScript, which runs with OS-level permissions. Screenshots need a rendering/display context. Linux CI, Windows acceptance, and specific macOS workflows are reported separately, not as equal coverage across clients and platforms.
