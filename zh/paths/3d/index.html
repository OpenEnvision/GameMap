开发路径

制作 3D 游戏

先做好一个空间和核心循环，再准备可进入引擎的游戏资产。

3D

Characters in action

项目预览

  • 3AGameFactory · Courtyard combat
  • 3AGameFactory · Village quest
01
开发步骤

规划与范围

定义相机、角色控制、核心交互和目标硬件，先做一个房间或关卡，控制 3D 项目的初始范围。

重点

从一个空间开始

主题

  • Vertical slice
  • Target device

交付物

关卡草图、交互清单和性能目标。

检查点

目标设备、画质设置和核心体验已经明确。

推荐工具

  • Level Design Book · unofficial design skill
  • Xbox Accessibility Guidelines
02
开发步骤

选择引擎

选择引擎、渲染器和物理方案，再接入 MCP 或编辑器自动化；同时考虑代码修改与场景、资产操作。

重点

搭好制作流程

主题

  • Unreal · Unity
  • Three.js · Godot

交付物

最小场景、编辑器集成和构建命令。

检查点

创建对象、运行场景和读取错误均有可重复的步骤。

推荐工具

  • Godot Engine · Official Documentation
  • Unreal Engine · Documentation
  • Unity · Manual
  • Three.js
03
开发步骤

实现游戏循环

在灰盒关卡中实现移动、相机、碰撞和关键交互，将运行状态和错误作为反馈提供给代理。

重点

让空间产生交互

主题

  • Agent frameworks
  • 游戏实录

交付物

灰盒关卡、角色控制器和交互状态机。

检查点

相机、碰撞、存档和重启在实际运行中表现正确。

推荐工具

  • Godot Demo Projects
  • Lyra Sample Game
  • Catlike Coding · Surface Contact
  • Three.js · Examples
04
开发步骤

制作游戏资产

生成或寻找模型后，检查比例、拓扑、材质、骨骼和动画，准备引擎可以稳定加载与使用的资产。

重点

让模型进入实际项目

主题

  • Mesh · Texture
  • Rig · Animation

交付物

GLB 或引擎资产、碰撞形状、LOD 与许可清单。

检查点

模型正确落地、比例一致，渲染和物理开销符合预算。

推荐工具

  • Blender
  • Khronos · glTF-Blender-IO
  • Hunyuan3D 2.0
05
开发步骤

试玩与迭代

在引擎中测试场景连通、角色行为、物理稳定性和帧时间，结合任务检查与视觉证据评估生成结果。

重点

同时验证行为与空间

主题

  • Runtime tests
  • Performance

交付物

运行测试结果、场景截图和性能采样。

检查点

交互可达、碰撞稳定、关键路线连通，性能达到目标。

推荐工具

  • Unreal · Automation Test Framework
  • Unity Test Framework
  • GUT · Godot Unit Test
  • Playwright Test
06
开发步骤

发布游戏

面向目标平台打包，清理未使用资产并验证加载，记录引擎、插件版本、硬件要求和复现步骤。

重点

打包完整体验

主题

  • Packaging
  • Optimization

交付物

安装包或网页构建、性能说明与复现指南。

检查点

目标设备上的全新安装可以完成一轮完整游戏循环。

推荐工具

  • Steam
  • Unreal Engine · Gauntlet
  • Unity · Addressables Build and Loading APIs
