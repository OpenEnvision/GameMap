实际使用注意事项

  • The 2.0 code and weights use the Tencent Hunyuan 3D 2.0 community license, not an OSI-style permissive license. The 2.1 repository is a separate release and is not substituted for this paper. Local shape generation needs about 6 GB VRAM; shape plus texture needs about 16 GB according to the 2.0 README.
  • Repository is public; an explicit open-source license was not established. Public visibility does not grant an open-source license.
