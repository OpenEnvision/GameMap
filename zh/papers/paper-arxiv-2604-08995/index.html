使用说明
Use the Matrix-Game-3 directory rather than the 4.0 root instructions. The 3.0 Quick Start documents Conda/Python 3.12 setup, FlashAttention, separate checkpoint download and torchrun generation on one or multiple GPUs. A/H-series Nvidia GPUs are tested. Its version-specific README and LICENSE.txt specify Apache 2.0, which takes precedence over the repository-root MIT file for this version. No local inference was executed.
