使用说明
Use the Matrix-Game-2 directory rather than the root README, which now documents 4.0. The 2.0 README supplies installation, checkpoint-download and inference/streaming commands. It requires an Nvidia GPU with at least 24 GB memory, compatible PyTorch/FlashAttention and separate model checkpoints. The README specifies MIT; its local LICENSE target is absent, while the repository-root MIT license is available. No local inference was executed.
