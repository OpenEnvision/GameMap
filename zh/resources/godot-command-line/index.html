Godot · Command Line Tutorial

Godot 官方命令行参考，涵盖无头运行、脚本检查、资产导入、执行和导出。

用途与特点

编程代理可用命令启动项目、读取日志、解析脚本和导出构建，减少对 GUI 的依赖。--check-only 仅解析 --script 指定的脚本，不执行玩法测试。支持的参数随构建类型变化，未知参数会被静默忽略，应检查当前二进制的 --help。无头运行不能替代真实渲染与输入测试。
