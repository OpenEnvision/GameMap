Codex · Create Browser-based Games

OpenAI 的浏览器游戏开发流程，涵盖规划、项目指令、资产生成和浏览器迭代。

用途与特点

先明确玩家目标、核心循环、输入和胜负条件，再结合 PLAN.md 与 AGENTS.md 实现。将图像技能和 Playwright 用于视觉与交互反馈。这是一份实践指南，不是针对所有游戏类型的性能保证或研究基准。
