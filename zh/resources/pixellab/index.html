PixelLab AI Agent Toolkit

通过 API 和 MCP 生成像素角色、动画及无缝瓦片集的资产工具。

用途与特点

根据角色描述、朝向、动作与地形条件生成像素资产，包括四向、八向角色，以及侧视或俯视瓦片集。它是商业资产服务；MCP 连接资产工具与编程代理，游戏规则、碰撞和资产导入仍需项目流程实现。
