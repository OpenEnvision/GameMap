Godot Engine · Official Documentation

通过场景、节点、资源和脚本组织项目的开源 2D / 3D 游戏引擎。

用途与特点

官方资料覆盖 GDScript、C#、场景和资源 API，可帮助代理把脚本改动连接到实际运行的场景。固定引擎版本并使用对应文档，stable 与开发分支不能混用。
