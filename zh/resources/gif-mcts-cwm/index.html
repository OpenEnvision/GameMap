GIF-MCTS / Code World Models Benchmark

通过生成、改进与修复的树搜索，合成可运行环境模型。

用途与特点

用 Python 表达状态转移、奖励与终止逻辑，由轨迹和测试反馈引导 GIF-MCTS 搜索。论文还发布覆盖 18 个强化学习环境的 CWMB，用于检查模型正确性与下游规划，是代码世界模型的基础阅读与评估参考。
