Playwright MCP

Microsoft 的浏览器自动化 MCP 服务，向代理提供页面结构、交互与浏览器反馈。

用途与特点

适合检查浏览器游戏的菜单、HUD、启动流程、键盘输入和截图。默认使用无障碍树，坐标鼠标工具需要可选 vision 能力；两者都不会自动暴露 Canvas 或 WebGL 内部状态，可能需要游戏调试接口。README 提醒该服务不是安全边界，browser_run_code_unsafe 可在服务进程中执行任意 JavaScript。独立的 Playwright CLI 仓库另提供 CLI + Skills 流程。

项目身份与署名

Official Microsoft Playwright project. Use the real Playwright brand mark; it is a Microsoft-maintained MCP, unlike third-party engine bridges.
