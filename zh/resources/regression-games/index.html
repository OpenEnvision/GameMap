Regression Games

提供公开 Unity SDK，用于玩法记录、输入回放和回归测试参考流程。

用途与特点

SDK 结合玩法记录、状态检查、输入回放、Bot 逻辑和验证，官方首测教程与 Boss Room UI 测试项目仍保存在 GitHub。适合作为集成参考：核查时旧文档域名不可达，当前托管服务与维护状态未确认。采用前检查 SDK 兼容性和服务依赖。
