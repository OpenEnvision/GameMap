Claude Code

支持读取项目、修改代码、调用工具，以及技能包、Hooks 和 MCP 的终端与 IDE 编程代理。

用途与特点

可用于游戏脚本开发、架构迁移、构建排错，并通过社区 MCP 服务连接 Unity、Godot 或 UE。结合 CLAUDE.md、技能包和编辑器状态使用；单个 MCP 演示不能替代完整引擎流程的验证。
