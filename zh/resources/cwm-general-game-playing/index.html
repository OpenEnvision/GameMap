Code World Models for General Game Playing

将自然语言游戏规则编译成可验证模拟器，用于 MCTS 规划。

用途与特点

根据规则和游戏轨迹生成 Python 状态转移、合法动作与终止函数，并为规划生成启发式价值及隐藏状态推断函数。论文评估十个完全或部分可观察游戏，包括棋盘与卡牌。能否避免非法动作取决于合成规则是否正确，模型验证仍然必要。
