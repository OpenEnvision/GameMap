3AGameFactory

通过技能包、模型流程和引擎适配器，协调游戏资产、玩法与 UI 制作。

用途与特点

编程代理将需求分流到图像、3D、动作、音频等流程，产出资产与引擎原生代码，提供 UE5、Unity、Godot、Blender 和 three.js 的相关上下文。演示混合使用生成与已有资源，名称中的 3A 并非经过验证的商业质量评级。它与可灵的 GameFactory 视频世界模型是不同项目。
