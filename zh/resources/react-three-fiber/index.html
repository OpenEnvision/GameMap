React Three Fiber

Three.js 的 React 渲染器，以组件和声明式方式组织 3D 场景。

用途与特点

适合结合网页 HUD、应用状态和 3D 场景，并使用 pmndrs 生态进行加载、交互和调试。它不提供全部游戏系统；应匹配 React、Fiber、Three.js 版本，并明确逐帧模拟的职责边界。
