UniGen

规划 Unity 原型、生成脚本、组装场景，并支持迭代调试的多代理流程。

用途与特点

研究从自然语言创建 Unity 游戏，仓库公开 Python 流程、模型连接器、安装指南与演示录像。需要 Unity 和模型服务账户。公开流程代码不等于可直接试玩的托管版本，基准游戏的完整可下载版本仍需确认。
