Phaser · First Game Guide

浏览器 2D 游戏框架，官方入门教程覆盖资产、场景、动画、输入和碰撞。

用途与特点

适合围绕 preload / create / update 快速搭建可在浏览器验证的核心循环。教程中的静态 Arcade Physics 对象缩放后，需要刷新碰撞体。场景可见后仍要检查输入、重启与生命周期。
