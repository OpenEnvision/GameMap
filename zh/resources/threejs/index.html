Three.js

面向浏览器的 JavaScript 3D 渲染库，提供场景、相机、材质和资源加载器。

用途与特点

可直接用 TypeScript 或 JavaScript 制作能在浏览器检查的 3D 原型，并从源码与示例研究 API。游戏循环、物理、导航、存档等系统需要另行设计或集成；WebGL 与 WebGPU 路径应分别验证。
