Gemini CLI

Google 开源的终端编程代理，提供文件访问、Shell 工具、扩展和 MCP 支持。

用途与特点

可帮助理解游戏项目、编辑脚本，并通过 MCP 操作编辑器。官方 README 说明，免费层和 Google One 用户自 2026-06-18 起迁移到 Antigravity CLI，且 Gemini CLI 并未针对最新 Gemini 模型优化。选择入口前应查阅对应账户的迁移说明。
