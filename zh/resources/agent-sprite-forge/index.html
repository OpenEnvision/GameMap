Agent Sprite Forge

将参考图、生成动画和确定性处理组合成可导出的精灵资产。

用途与特点

从已确认的参考图生成动作片段，再进行去背景、对齐、循环选段、时序修正和图集打包，支持 Godot、Aseprite 与网页导出。0.4.0 的 README 仅报告解析层往返检查，未验证 Godot、LDtk 或 Aseprite 编辑器导入，仍需实际导入和视觉验收。
