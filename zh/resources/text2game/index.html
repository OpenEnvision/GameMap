Text2Game

把长文本转成世界、角色和事件数据，用于叙事游戏原型。

用途与特点

分块分析文本、合并结果，并生成 Twine / Chapbook HTML 或 Godot 视觉小说项目。仓库提供 Python 流程与示例，适合研究叙事到可玩原型的转换，不是任意动作游戏的通用生成器。

主题

  • Interactive narrative
  • Twine
  • Godot
  • Visual novels
