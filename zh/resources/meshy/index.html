Meshy API

将 AI 模型生成、人形绑定和动画导出接入游戏资产流程的 API。

用途与特点

官方动画角色流程把参考图转成带纹理、骨骼和待机、跳跃、攻击片段的角色，输出 GLB 和 FBX；动画阶段使用 Meshy 动作库。API 绑定更适合肢体清晰分离的标准带纹理双足角色。生成资产仍需引擎导入、碰撞、控制与性能检查；公开 cookbook 提供的是资产示例，而非完整玩法。
