DirectX Shader Compiler

通过 dxc 命令行或编译器 API 编译 HLSL 的工具。

用途与特点

编译器调用成功与着色器编译成功是不同结果，应检查返回状态、诊断和所需输出。目标 profile、include 依赖和构建配置都会影响结果。编译后的着色器仍需验证渲染正确性与目标设备兼容性。
