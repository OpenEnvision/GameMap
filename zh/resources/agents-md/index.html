AGENTS.md

用 Markdown 向编程代理说明构建命令、测试规则和项目约定的开放格式。

用途与特点

游戏项目可记录引擎版本、启动命令、目录规则、资产导入约定和验收检查，减少环境配置中的猜测。它是项目指令格式，而不是代理运行时；文件发现和配置方式因客户端而异。
