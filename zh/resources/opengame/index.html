OpenGame

使用可复用模板与调试技能生成浏览器游戏项目。

用途与特点

通过 Template Skill 和 Debug Skill 将自然语言需求转成 Canvas、Phaser、three.js 等网页项目。公开 CLI 支持 OpenAI 兼容模型端点，论文另介绍 GameCoder-27B。浏览器执行与视觉评判检查构建、可用性和意图对齐；README 仍将独立评估流程列为后续发布内容，框架公开本身不代表模型权重和完整评估均可复现。
