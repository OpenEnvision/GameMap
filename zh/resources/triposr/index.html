TripoSR

从单张图像快速重建 3D 物体，适合资产原型制作。

用途与特点

使用 LRM 风格的前馈重建，公开代码、预训练模型与演示，将图像转为可导出的物体网格。重点是单个物体，隐藏表面、拓扑和游戏性能需后续处理，不是完整场景或可玩游戏生成器。

主题

  • Image-to-3D
  • Reconstruction
  • Mesh
  • Prototype assets

开发阶段

  • 资产与动画

适用方向

  • 3D

项目身份与署名

The official README explicitly says TripoSR was collaboratively developed by Tripo AI and Stability AI. The VAST-AI-Research organization links to tripo3d.ai. This shows Tripo/VAST as one verified co-developer, not as the sole author.
