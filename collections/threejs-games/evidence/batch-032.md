## Ascend — Stack to the Stars

- Source: [YASH-MOHARIR/Game-Ascend](https://github.com/YASH-MOHARIR/Game-Ascend/tree/e91e4946f11a6a004205d5a2d84f119bfd4c7c20), commit `e91e4946f11a6a004205d5a2d84f119bfd4c7c20`.
- Rendering: The React component's imperative effect directly constructs THREE.WebGLRenderer, scene/camera and block meshes. Its own requestAnimationFrame updates the active stack/camera and calls renderer.render. React/react-dom supply DOM UI and state; the scene is not composed through R3F. [Renderer source](https://github.com/YASH-MOHARIR/Game-Ascend/blob/e91e4946f11a6a004205d5a2d84f119bfd4c7c20/src/App.jsx#L242).
- Game loop: Placing a block computes overlap against the previous block on alternating axes. No overlap drops the block and calls endGame; partial overlap slices away the overhang, shrinks the next placement surface and increases the stack score. Perfect placements build a combo. The actual render/input loop drives these actions, with game-over/restart and local score UI. [Gameplay source](https://github.com/YASH-MOHARIR/Game-Ascend/blob/e91e4946f11a6a004205d5a2d84f119bfd4c7c20/src/App.jsx#L431-L454).
- Dependencies: React 18/react-dom are DOM hosts, Three owns rendering, Tone.js synthesizes sound, and project code handles slicing/stack rules. Vite/Tailwind and the React Vite plugin are build/style tools; exact declared strings are retained. The separate game.html entry embeds JSX with CDN React 18, ReactDOM, Babel standalone, Tailwind, Three 0.160.0 and unversioned Tone. The Vite entry instead declares Three ^0.170.0/Tone ^15.0.4. The 'portable' HTML therefore still needs its CDN dependencies; it is not verified as an offline standalone bundle. [package.json](https://github.com/YASH-MOHARIR/Game-Ascend/blob/e91e4946f11a6a004205d5a2d84f119bfd4c7c20/package.json)
- License: MIT (code). Root MIT text is present and package.json agrees. README describes procedural blocks and synthesized Tone.js audio; the reviewed scene/audio source is consistent with that description. Runtime libraries/CDN packages retain separate licenses, and full authorship/transitive provenance was not exhaustively audited. PulseStack-3D is an explicitly renamed collaborative copy with identical game-source/license/manifest blobs, so this canonical project is counted once. [License file](https://github.com/YASH-MOHARIR/Game-Ascend/blob/e91e4946f11a6a004205d5a2d84f119bfd4c7c20/LICENSE). [Additional notice](https://github.com/YASH-MOHARIR/Game-Ascend/blob/e91e4946f11a6a004205d5a2d84f119bfd4c7c20/README.md).
- Maturity: game. Active source implements placement, shrinking overlap, perfect combos, stack score, game-over and restart. README calls it a rhythm/precision game, but no specific beat-judgment/music-timing mechanic is asserted by this review. [Maturity basis](https://github.com/YASH-MOHARIR/Game-Ascend/blob/e91e4946f11a6a004205d5a2d84f119bfd4c7c20/README.md).
