- Maturity: legacy-prototype. Source implements 3D paddle/ball play, first-to-five scoring and winner/reset flow. The network backend and old browser APIs remain untested. [Maturity basis](https://github.com/erichlof/SpacePong3D/blob/b4b30fe0bde4710fd5ffd6350aeccb1076497caf/README.md).

Legacy PubNub/WebRTC matchmaking, opponent invitations and audio were not invoked; no real user or service was contacted through the game. [package.json](https://github.com/hookerz/spot-the-bot/blob/579b3f8e3e71dea42d3528e6501b89da4f9720ef/package.json)
- License: Apache-2.0 (code). Root Apache-2.0 text verified. Bundled robot art, sounds, fonts and third-party scripts were not exhaustively rights-audited; the code notice does not establish identical terms for every asset. [License file](https://github.com/hookerz/spot-the-bot/blob/579b3f8e3e71dea42d3528e6501b89da4f9720ef/LICENSE). 
- Maturity: legacy-prototype. An older cooperative picker/helper game with full target, timer, scoring and finished-state logic. README includes a 2018 warning about legacy WebVR API support. [Maturity basis](https://github.com/hookerz/spot-the-bot/blob/579b3f8e3e71dea42d3528e6501b89da4f9720ef/README.md).

Text reader returned 502; that does not establish permanent downtime or runtime playability. [Discovery source](https://github.com/hookerz/spot-the-bot/blob/579b3f8e3e71dea42d3528e6501b89da4f9720ef/README.md).

Firebase initialization/rooms, Facebook API hooks, analytics and multiplayer were not invoked; backend availability is unknown. Vue is the UI layer; actual game rendering is imperative Three.js. ## First Person Shooter JS

- Source: [davidinfante/First-Person-Shooter-JS](https://github.com/davidinfante/First-Person-Shooter-JS/tree/1761f5758816aeb83ee4b9bf703c26b96a3bd284), commit `1761f5758816aeb83ee4b9bf703c26b96a3bd284`.
- Rendering: The actual FPS entry constructs THREE.WebGLRenderer directly. TheScene extends the Physijs physics scene while Three.js remains the renderer. [Renderer source](https://github.com/davidinfante/First-Person-Shooter-JS/blob/1761f5758816aeb83ee4b9bf703c26b96a3bd284/fps/script.js#L177).
- Game loop: Ammunition reaching zero invokes endGame, stops controls and shows total score with P to restart. Enemy collision handlers add ten points and advance after four counted targets; newGame resets ammunition/score. [Gameplay source](https://github.com/davidinfante/First-Person-Shooter-JS/blob/1761f5758816aeb83ee4b9bf703c26b96a3bd284/fps/TheScene.js#L231).
- Dependencies: Vanilla JS; Three.js/PointerLockControls/OBJ/MTL loaders with Physijs/Ammo physics, jQuery, dat.gui, stats and Howler. The actual script list is in fps/index.html; no npm manifest was located. 
- License: GPL-3.0 (only/or-later variant unconfirmed). Root contains GPL version 3 text; a project-specific only/or-later choice was not established, so SPDX remains null. Models, sounds, textures and bundled dependency terms were not exhaustively audited. [License file](https://github.com/davidinfante/First-Person-Shooter-JS/blob/1761f5758816aeb83ee4b9bf703c26b96a3bd284/LICENSE.md). 
- Maturity: legacy-prototype. An educational FPS prototype with ammunition, targets, score, level advancement and end/restart UI. This is source verification, not gameplay or collision-correctness verification. [Maturity basis](https://github.com/davidinfante/First-Person-Shooter-JS/blob/1761f5758816aeb83ee4b9bf703c26b96a3bd284/README.md).
- Demo:  `not-located` on 2026-10-23. README documents local serving, not a confirmed public author demo; no Pages URL was guessed. [Discovery source](https://github.com/davidinfante/First-Person-Shooter-JS/blob/1761f5758816aeb83ee4b9bf703c26b96a3bd284/README.md).
- Review limits: Enemy collision callbacks/counting and hit attribution were not run; player health/survival mechanics are not claimed. Legacy Physijs/Ammo worker loading, pointer lock, imported weapon/scene assets and modern-browser compatibility were not exercised. GPL code evidence does not resolve all imported model/audio/texture rights.
- Runtime status: source reviewed; **not built, not playtested; upstream tests not run**.
