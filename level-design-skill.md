# Level design skill

Plan layouts, greyboxes, encounters, and playtests with task guides and reusable templates adapted from [The Level Design Book](https://book.leveldesignbook.com/). Start with a design question, build a playable slice, and use observations to guide the next change.

## Read or install

- [Read the skill and its task routing](skills/level-design/SKILL.md).
- [Download the complete skill package](./skills/level-design.zip). Extract the `level-design/` directory into the skill directory supported by your chosen client; consult that client's instructions. No engine integration is installed automatically.
- [Read the adaptation license and third-party exceptions](skills/level-design/LICENSE.md).
- [Inspect the reported source map and unfinished sections](skills/level-design/references/source-map.md).
- Start with a [level brief](skills/level-design/templates/level-brief.md), a [playtest report](skills/level-design/templates/playtest-report.md), or a [review](skills/level-design/templates/review.md).

The package contains instructions, thirteen topical/source references, and three templates. It primarily addresses 3D levels, with explicit assumptions required for 2D and other contexts. It does not bundle book screenshots, game assets, linked videos, external articles, or pi configuration.
