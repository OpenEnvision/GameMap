# GameMap 静态网页

本目录仅保留现有网页及其运行所需文件，首页是 `index.html`。无需 npm、构建工具或安装项目依赖。

本地预览：

```sh
python3 preview.py
```

打开 http://127.0.0.1:4173/GameMap/ 。按 Ctrl+C 停止。直接双击 HTML 无法完整运行模块和页面导航。

部署到 GitHub Pages 时，使用 `GameMap` 仓库，选择 `main` 分支和 `/(root)`。本版本的地址前缀为 `/GameMap/`；其他托管服务也需将本目录挂载到这个路径。

请保留文件的相对位置。`assets/` 是编译后的网页脚本和样式；`.data` 是页面导航数据；两份 `search-index.json` 用于中英文搜索。它们属于运行文件。

源码、依赖、测试、设计原稿和旧打包文件已另存到项目目录外的完整备份。如需重新生成网页，请使用备份中的开发项目。

论文列表和搜索结果中的论文标题直接打开原始论文或来源网站，不再生成站内论文详情页。
