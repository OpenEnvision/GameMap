Sprout Quest

Explore a small world, fight real-time arena battles, gather materials, craft gear and rebuild a village. Sprout Quest is a mobile-first adventure with a 2D world and live-rendered 3D characters and items.

AI workflow / foundation context

The creator says Claude Code generated the game, tests and Blender art pipeline from plain-language requests while the human played on a phone and gave feedback. The repository contains the runtime art as well as its source builders.

Study this workflow

  1. Play the portrait-browser prologue and follow its first fight, gathering and forge tasks.
  2. Read the build account to see how human phone playtests guided later Claude Code changes.
  3. Run bun install and bun run dev; inspect the game modules, committed runtime assets and Blender builders.
  4. Change one combat, crafting or story rule with an agent, then replay the affected progression and save flow.
