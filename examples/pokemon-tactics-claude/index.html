Pokemon Tactics

Move Pokemon across an isometric battlefield, use elevation and aim area attacks without hitting allies. This playable tactical fan game combines a TypeScript simulation with 2D-HD sprites on Babylon.js terrain.

Engine

AI workflow / foundation context

The creator directs design and architecture while Claude Code writes most code, tests and documentation with specialist agents. Pokemon data, sprites and some PixelLab artwork have separate credits and rights.

Study this workflow

  1. Play a battle against the built-in opponents and test movement, height, type matchups and friendly fire.
  2. Read the AI disclosure and CREDITS.md before exploring the engine and rendering packages.
  3. Use Node 24 or later and pnpm 10.32.1 to run the complete workspace locally.
  4. Change one tactical rule with an agent, then compare battle resolution, team setup and replay behavior.
