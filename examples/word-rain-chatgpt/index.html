Game example

Word Rain

Move a basket to catch letters in the right order, complete shuffled words and survive red hazards. Shields, wildcards, perfect-word streaks and changing falling speed add decisions to the arcade spelling loop.

AI workflow / foundation context

octopuskid designed and refined the game, while ChatGPT/Codex assisted with code and interface text. The original tune and sound effects are synthesized in code with ChatGPT assistance. Two optional Kevin MacLeod recordings have separate credits; they are not AI-generated music.

Study this workflow

  1. Start the browser game and move the basket with the arrow keys, A/D or pointer dragging.
  2. Read the creator’s AI disclosure and compare the browser and Android editions.
  3. Open index.html with the bundled assets/music directory, or use the self-contained Lite download for offline browser play.
  4. Trace letter spawning, catches, shields and score updates in the Canvas game; check pause and resume before changing a rule.
