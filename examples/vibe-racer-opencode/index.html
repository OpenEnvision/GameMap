Play or run

  • Download and run Vibe Racer

    No hosted browser build. Requires Python 3.12+ and Pygame 2.6.1+. Run uv run -m src.main; alternatively pip install -e . then python -m src.main. Arrow keys drive, R restarts, G toggles the ghost, and B returns to track selection. Source-checked launch steps; not executed.

Project source

  • Open the complete racing project

    MIT-licensed game source with supplied maps, replays, screenshots, and pyproject.toml/uv.lock. Python 3.12+; the graphical game needs a local desktop display.
