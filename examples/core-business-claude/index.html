Core Business

Drill for minerals, manage fuel and hull condition, and spend earnings at surface shops in a non-commercial mining tech demo inspired by Motherload. Three.js renders the 2.5D world while Blender scripts produce its 3D assets.

AI workflow / foundation context

The creator attributes the game code, tests, textures, translations, models and Blender generation scripts to Claude Opus 5.5. ElevenLabs supplied the sound and music. The project reimplements Motherload-style rules with new assets and explicitly describes itself as a non-commercial experiment; the coding client is not named.

Study this workflow

  1. Start a new game and learn movement, downward drilling, fuel and return-to-surface shops.
  2. Read the fixed-step simulation separately from the Three.js renderer and committed GLB models.
  3. Serve the repository root with a static HTTP server; opening ES modules via file:// does not work.
  4. Change one mineral or upgrade rule, then check drilling, selling, fuel use and save/reload.
