Beach Kitty

A cat-led Phaser campaign that combines running, platforming, shooting, and other arcade mechanics, with optional generated cat art.

AI workflow / foundation context

The creator credits Claude Code and Google Gemini. The public project includes development progress logs, architecture notes, game scenes, and assets; Gemini also powers optional cat customization.

Study this workflow

  1. Play the campaign and compare how its scenes share one cat character.
  2. Read the progress log alongside the author’s Claude Code and Gemini disclosure.
  3. Inspect the Phaser scenes and React shell to understand their responsibilities.
  4. Run npm install and npm run dev; the core game runs without a Gemini key.
