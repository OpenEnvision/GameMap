AI workflow / foundation context

Hirotaka Adachi names Claude Code as the development tool and SUNO AI for music, and describes the work as entirely AI-created. The exact coding model is not identified. The public project contains the game renderer, rules, interface and four music files; the creator’s claim does not establish autonomous development without human direction.

Study this workflow

  1. Run the browser game, choose a new game and language, and confirm the opening and tutorial with Enter.
  2. Use the arrow keys to explore the first room, Space to defend and X to open the command menu.
  3. Read the creator’s AI disclosure and inspect the complete HTML, CSS, JavaScript and music files.
  4. Serve the source folder over HTTP, change one room or stamina rule, and check movement, interactions and a new run.
