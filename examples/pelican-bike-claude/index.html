Pelican on a Bike

Ride a helmeted pelican along a procedural coast, change lanes to catch fish, jump and unlock small achievements. The complete Three.js project includes its own character, bicycle, ocean, audio and day/night systems.

AI workflow / foundation context

The creator reports generating the game with Claude Opus 5.5 in Claude Code from one Chinese sentence. The README publishes that prompt and describes model-led browser testing and later fixes; the no-manual-code claim is the creator’s, not a measured authorship audit.

Study this workflow

  1. Start a muted ride, accelerate with W/S, change lanes with A/D and jump with Space.
  2. Compare the published one-sentence prompt with the pelican, bicycle, cloth, ocean and camera modules.
  3. In pelican-bike, install dependencies and run node build.mjs; open the resulting dist/index.html in a browser.
  4. Change one collection or cycling rule, then check movement, jump, score feedback and restart.
