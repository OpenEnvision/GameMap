Project Plateau: Proof Before Dark

A first-person field-photography expedition inspired by The Lost World: frame prehistoric animals, manage four photographic plates, avoid threats and return to camp before daylight fades.

AI workflow / foundation context

The creator presents Project Plateau as a NovelToGame adaptation built through analysis, concept, world design, art direction, implementation and QA stages. The public workspace includes game code, committed models and textures, asset-generation scripts and the input trace for one tested path; its coding client is not explicitly identified.

Study this workflow

  1. Start the desktop expedition and learn movement, camera, crouching and return-to-camp controls.
  2. Compare how subject framing, cover and photographic plates create choices from the novel’s expedition premise.
  3. Read the build brief and verification record to separate a tested route from untested device, sound and optional encounter behavior.
  4. For local play, enter examples/project-plateau/build/app, use Node 22.12+ to install dependencies, then run npm start; the committed runtime assets do not require Blender regeneration.
