AI workflow / foundation context

The creator combined a PRD, technical design and curated asset metadata with three Claude Code skills for Phaser gameplay, tilemaps and frontend testing. Human-made Tiny Swords assets are credited separately; this is a prototype.

Study this workflow

  1. Play a two-player battle and identify recruitment, movement, attacks and castle victory conditions.
  2. Read the published PRD and technical design before tracing the game’s single-file scene logic.
  3. Inspect the Tiny Swords asset metadata and the custom panels used to handle sprite padding.
  4. Change one unit or UI rule with an agent, then replay the battle and inspect the included test harness.
