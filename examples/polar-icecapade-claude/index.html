Game example

Polar Icecapade

Slide across icy 3D arenas, use a three-hit melee combo to propel yourself forward, and fire projectiles that push you backward. Open gates and collect coins while confronting a rat regime in a short game-jam adventure.

AI workflow / foundation context

Aidan “Botodo” Connolly and Evan Kurtz describe Claude Code helping diagnose problems and implement difficult core logic; they then touched and tweaked all code. They modeled, rigged, animated and designed the game themselves, using credited external audio. They explicitly state that generative AI was not used to create assets. No coding model version is supplied.

Study this workflow

  1. Start the first browser level with a mouse and test the slippery movement and melee combo.
  2. Use right-click shooting and compare its backward recoil with forward melee propulsion.
  3. Read the team’s Claude Code disclosure and human art, animation and audio credits.
  4. Open the slick project folder in Godot 4.6, change one movement or gate rule, and test the first room, ammo and pause/restart controls.

Play or run

  • Play or download Polar Icecapade on itch.io

    Mouse recommended: left-click performs melee propulsion, right-click shoots with recoil, and Escape pauses. Browser review reached the first level, moved, fired a projectile with ammo changing from 12 to 11, and opened pause. The roughly 170 MB web build has author-documented performance limits; Windows/Linux downloads are provided and mobile is not recommended. Later levels and a complete run were not tested.

Project source

  • Open the complete Godot game project

    Complete Godot 4.6 project with levels, GDScript, GLB/FBX models, Blender authoring files, textures, UI and audio. The inspected tree has 292 files, about 239 MB. Open the slick folder; importing Blender authoring files may require a compatible Blender installation. No top-level game license was found; external sounds, music and fonts retain their separately credited terms.
