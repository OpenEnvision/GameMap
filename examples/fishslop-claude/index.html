Game example

Fishslop

Pilot a bathyscaphe through a sunken reef, feed fish, collect the coins they drop and buy new residents or submarine parts. Sonar briefly reveals an otherwise invisible Veilfin.

AI workflow / foundation context

The creator’s initial implementation and subsequent fixes explicitly credit Claude Opus 5.5 as a commit co-author. This is evidence of an AI-assisted development contribution; it does not identify the coding client or establish that all code was generated by the model. The reef, fish, textures and sounds are generated by game code.

Study this workflow

  1. Dive in, steer with WASD, hold Space to feed fish and use F for sonar.
  2. Compare the renderer-free simulation, feeding economy and save parser with the Three.js scene.
  3. Use a Vite-compatible Node runtime, npm ci and npm run dev; Node 22.12+ meets the current Vite 8 requirement.
  4. Change one fish or upgrade value, then check food, dropped coins, dock purchases and saved progress.

Play or run

  • Play Fishslop

    WebGL2 with keyboard, mouse or touch. WASD steers, E/Q changes depth, Space feeds, F pings sonar and B opens the dock. The low-quality preset ?quality=low&scale=0.5 was used to check steering, feeding, coin feedback and sonar.

Project source

  • Open the complete game project

    Complete simulation, Three.js renderer, procedural assets, UI, audio, lockfile and tests. npm ci then npm run dev; the README’s Node 20.19+ does not cover every Node 22 version supported by its current Vite 8 dependency, so use Node 22.12+ or another compatible current runtime.
