Play or run

  • Download and run Vibe Jet

    Current hosted availability was not verified in this source-only pass. With Node.js 18+, run npm install. Start a static server with npx serve, then run npm start in a second terminal; npm start starts only the WebSocket server on port 8080; the browser client connects to ws://localhost:8080. Open /game.html on the static server address. Desktop keyboard/mouse required. These launch instructions were source-checked, not executed.
