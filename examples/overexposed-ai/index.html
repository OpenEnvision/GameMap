Overexposed

Guide a rising performer through a year of career choices in a card-based fame simulation. Play cards to build craft, money and attention while three newspapers react and excessive heat turns into scandals.

AI workflow / foundation context

EG30 provides design, direction and writing, using Claude Code and OpenAI Codex for implementation. AI-assisted drafts of player text are edited by the creator. Art and sound effects are drawn or synthesized in code with AI assistance; the Holizna background recordings are separately credited CC0 music.

Study this workflow

  1. Open the itch.io browser build, choose Begin and Continue, then sign with a manager.
  2. Select an opening card offer and inspect how the desk, resources and newspapers respond.
  3. Read the creator’s AI disclosure, README and CREDITS.md to separate code-generated art and effects from third-party music.
  4. Use Node.js 22.18+ with npm install and npm run dev; trace content/cards.json through core/reducer.ts and the React desk before testing a complete year.

Play or run

  • Play Overexposed on itch.io

    Browser playtest build, best on a landscape desktop screen. Uses mouse or touch; cards show effects on hover or long press. Begin, opening text and manager choice reached the live card desk in Chrome. The complete year, all endings and touch play were not tested; the hosted build is not claimed to match the latest repository revision.

Project source

  • Open the complete career-simulation project

    Complete TypeScript/React project with the rule engine, content, UI drawings, procedural sound, six music files, fonts, balance simulator and browser checks. Node.js >=22.18; npm install, npm run dev or npm run build. No explicit software license is provided, so public source availability does not establish reuse rights. Bundled fonts are OFL 1.1 and Holizna music is CC0; see CREDITS.md.
