Play or run

  • Play Clowder & Crest

    Browser campaign with mouse/touch minigames. The title screen also offers a spoiler-marked unlocked minigame archive. Android/iOS packaging is included, but native installation has separate platform requirements. Initial asset loading can be slow.

More ways to play

  • GitHub Releases · Android

    Download — Signed v2.8.0 Android APK for sideloading. This is not a Google Play listing. Installer assets were verified; installation was not tested.

  • GitHub Releases · iOS

    Download — Older v2.7.3 IPA; iOS is not included in v2.8.0. Requires suitable signing and sideloading as described by the author, not direct App Store installation. Not installed in this review.

Project source

  • Open the complete guild-game project

    Full Phaser campaign, fifteen minigame types, assets, native shells and tests. Install package dependencies, then npm run dev; the documented dev port is 3200. CC BY-NC-SA 4.0.
