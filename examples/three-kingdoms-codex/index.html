AI workflow / foundation context

MartinDelophy supplied the strategy-game direction and requested more officers, portraits and balance changes. GPT-6 Astra in Codex iterated on rules, interface, data, opponents, saves and tests; a separate image tool generated terrain and portrait atlases.

Study this workflow

  1. Choose a faction and inspect a city and its officers.
  2. Read the creation record and portrait provenance.
  3. Execute an economic order and follow its resource and officer effects.
  4. Change one economy or combat rule and test turns, opponents and saves.

    Includes rules, interface, 108 officers, generated terrain and portrait atlases, tests and deployment configuration. Node.js 22.13+; npm ci then npm run dev from works/three-kingdoms. Static export uses dist/client. Repository CC0; dependencies retain their own terms.
