Explore procedural Backrooms in a first-person, turn-based roguelike. Moving or waiting triggers combat, while equipment combinations and sanity shape each run.

AI workflow / foundation context

Drew Brereton identifies the game as code-assisted by Claude. The project credits specifically name Claude Code and distinguish original work from external shaders, textures, and fonts.

Study this workflow

  1. Play the interactive tutorial and compare moving, waiting, equipment, and sanity.
  2. Read the creator’s AI disclosure and the project’s separate attribution file.
  3. Import project.godot in Godot 4.6 and inspect the start menu, procedural levels, and turn systems.
  4. Change one equipment or turn rule, then test a complete run and restart.
