AI workflow / foundation context

The authors present this as a single-prompt OpenGame result. Use the published brief and generated project to study how an agent connects game rules, assets, and interaction.

Study this workflow

  1. Open the live game, press Enter to start, and try placing towers and clearing obstacles.
  2. Compare the playable towers, waves, and building space with the original author prompt.
  3. Download this game’s archive and trace one mechanic from input through game state to feedback.
  4. Use the framework quick start for a new attempt, then compare the result against the same brief. Generation requires your own provider access.
