Game example

8-Second Crew · 8초 도둑단

Record an eight-second route, replay it as a clone and cooperate with earlier selves to steal a key and escape. Nine stages introduce pressure plates, patrols and projectiles.

AI workflow / foundation context

DongJae Shin set the rules, difficulty and presentation, while Codex helped plan and implement stages, collision, replay, interface, tests and deployment. Agent Sprite Forge processed generated character sprites; the creator repeatedly playtested the result.

Study this workflow

  1. Start the first stage and learn movement, keys and exits.
  2. Read the creator’s Codex development account and asset credits.
  3. Press X to record a route, then inspect how the clone replays it.
  4. Change a stage or replay rule and test a complete escape and restart.

Play or run

  • Play 8-Second Crew

    Korean, English and Japanese; keyboard, click-to-move and touch. WASD/arrows move, X records a clone, Z lures guards, and R restarts. Wait through the brief Ready countdown before moving.

Project source

  • Open the complete game project

    Complete static project with modules, nine stages, sprites, fonts, tests and demo recording. Node.js 18+; npm start, with no dependency installation. Code has no explicit license; the bundled Galmuri font uses OFL.
