Journey to the West: Three Borrowings of the Banana Fan

A Chinese turn-based RPG with painted walking maps, quests, equipment, pets and command battles, adapted from the Banana Fan chapters of Journey to the West.

AI workflow / foundation context

Zenstory publishes this as a NovelToGame agent-workflow result, with source analysis, rejected concepts, game and art direction, generated artwork, game implementation and QA records. The example does not identify one specific coding client; support for several clients is not proof that all were used.

Study this workflow

  1. Play the village and use the quest tracker to reach an NPC or a battle.
  2. Compare the novel chapter references with the selected fan, transformation and five-element mechanics.
  3. Read the design, art and QA files to distinguish implemented systems from deliberately omitted multiplayer features.
  4. To run locally, serve examples/journey-to-the-west/build/app with python3 -m http.server 5173; inspect the JavaScript battle implementation before changing a rule.
