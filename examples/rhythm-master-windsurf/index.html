Rhythm Master 3D

A four-lane music game with generated synth tracks, difficulty settings, combos and a special mode, implemented as a single browser HTML file.

AI workflow / foundation context

Frank Niu links this game from a creator post describing a Claude Sonnet 3.7 web-chat-to-Windsurf workflow: generate an initial game, diagnose issues in chat, then apply changes in Windsurf. It is a human-steered coding example, not evidence that Claude Code or a single autonomous run built it.

Study this workflow

  1. Download the repository and serve its directory with a local HTTP server, then open rhythm.html.
  2. Choose a track and difficulty, start the game, and use D/F/J/K as notes reach the target zone.
  3. Test combo scoring, Escape pause and the Space special mode before changing timing or difficulty.
  4. Compare the single-file implementation with the creator’s original brief and debugging workflow.
