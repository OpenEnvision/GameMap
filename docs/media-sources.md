# GameMap demo media sources

Homepage previews are excerpts from recordings published by the project authors. The credits below link each clip to its original source.

The previews retain every part of the source frame, including original game interfaces and input/output comparison labels. Only excerpt selection, proportional resizing, frame-rate normalization (maximum 30 fps), H.264 encoding, audio removal, and first-frame WebP poster encoding were applied to the six primary excerpts. Square footage and wide comparisons use a quiet matte instead of cutting off content. Native frame proportions are used in the lower gallery when practical. The mobile comparison variant additionally rearranges the two complete source panels as described below; it does not crop, replace, or generate any scene content.

## AI game tutorial screenshots

Reviewed October 20, 2026. All 88 game cases have a real-game preview with explicit provenance: 44 GameMap captures from linked browser builds, 5 local source-project captures, and 39 creator-published gameplay screenshots or recording stills. The page badges distinguish these origins. Creator images have a source-review date, not an invented capture date. These are game pixels, not generated illustrations or reconstructed promotional artwork. Optional engine foundations are excluded.

Images are proportionally resized and centered on a 1280 × 720 canvas without cropping game content. The [manifest](../website/public/assets/media/learning/manifest.json) records origin, source URL, capture or review date, dimensions, file size, and SHA-256. Creator images also retain their original image URL. Underlying art, characters, and interfaces remain credited to their creators and rights holders.

Tower of Time is captured from the [embedded build](https://html-classic.itch.zone/html/14174112-1308836/index.html?v=1782540129) exposed by the author’s Run game button. Its complete 640 × 480 canvas is centered on a dark matte. Other browser captures retain their complete viewport. Agent Arcade uses zero-based frame 20 from the creator’s Ninja Runner GIF; its transparent desktop overlay is part of the actual game presentation. No scene, character, HUD element, or text was generated or added.

Runtime review covers loading, selected gameplay interactions, and screenshot provenance. It is not a full game-completion or cross-browser certification. Orb Shooter and Midnight Pumpkin Hunt rendered their game scenes, but automated pointer-lock aiming/movement was limited by headless Chromium. Known unavailable public domains for Vibe Jet and FragArena use clearly labeled local source downloads. Mini KSP was played from unmodified local source. The Garden Match preview, when local, uses its documented development Canvas fallback; its public asset loading was slow in the review environment.

Cloud Crush uses the publisher's `screenshots/09_gameplay.png` at pinned source revision `cdded29daeb83a24d37dc5c7ead5c85d8a08ff89`. The complete 687 × 500 frame is preserved, including its original browser-automation status bar, and fitted onto the shared 1280 × 720 matte. It is credited as a creator screenshot; no local Cloud Crush execution is claimed. Dinosaur Game Offline was captured at 1280 × 720 from the author's live GitHub Pages build after normal Space-key start and jump inputs. The original run sprites were allowed to load before capture; the game code and displayed scene were not modified. Start, scoring, jump, collision, and restart passed with no JavaScript errors or failed requests in the final capture run.
