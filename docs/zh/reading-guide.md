# 怎样使用这份资料库

从当前遇到的问题出发，找到合适的工具、可参考的项目和下一步的做法。

## 按你的问题进入

- **还没有项目**：从[实践指南](practical-guide.md)开始，确定交付物和最小可玩循环。
- **想研究别人怎么做**：先在[游戏案例](/examples/)的中文界面筛选项目，再看作者开发记录、试玩和源码；[英文案例研究](../tutorials-and-demos.md)提供详细整理。
- **要选代理或引擎接口**：看[代理工作流（英文）](../coding-agent-game-code.md)，注意客户端、模型、Skill 和引擎桥接不是同一层。
- **已经在做关卡**：看[关卡设计 Skill 导览](level-design-skill.md)，先验证体验与空间关系，再增加资产。
- **准备验证与交付**：先在[测试资源](/testing/)选择任务环境，再按需要深入[测试资料（英文）](../game-testing-library.md)和[生产研究入口（英文）](../research-index.md)。

## 看材料时，保留三个区分

**存在不等于可用。** 有代码、文件或演示，并不代表依赖齐全、能在你的版本运行或已经验证过质量。

**能运行不等于能发布。** 代码、资产、权重和服务可能适用不同的许可，发布前需要分别确认。

**观察不等于结论。** 截图、通过提示或一轮成功，不能替代明确的测试任务、状态、失败条件和实际证据。

## 语言与版本

中文入口提供使用指南和部分主题导读；详细研究原稿仍有大量英文材料。标为“英文”的链接不会被自动当成中文译文。

需要确认工具版本、接口参数或使用条件时，沿条目中的来源链接查阅官方文档。
