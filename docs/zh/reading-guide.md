# 怎样使用这份资料库

从当前遇到的问题出发，找到合适的工具、可参考的项目和下一步的做法。

## 按你的问题进入

- **还没有项目**：从[实践指南](practical-guide.md)开始，确定交付物和最小可玩循环。
- **想研究别人怎么做**：看[游戏案例与源码](tutorials-and-demos.md)，分清作者描述和实际可检查的材料。
- **要选代理或引擎接口**：看[代理工作流](coding-agent-game-code.md)，注意客户端、模型、Skill 和引擎桥接不是同一层。
- **已经在做关卡**：看[关卡设计 Skill 导览](level-design-skill.md)，先验证体验与空间关系，再增加资产。
- **准备验证与交付**：看[测试资料](game-testing-library.md)和[生产研究入口](research-index.md)。

## 看材料时，保留三个区分

**存在不等于可用。** 有代码、文件或演示，并不代表依赖齐全、能在你的版本运行或已经验证过质量。

**能运行不等于能发布。** 代码、资产、权重和服务可能适用不同的许可，发布前需要分别确认。

**观察不等于结论。** 截图、通过提示或一轮成功，不能替代明确的测试任务、状态、失败条件和实际证据。

## 语言与版本

正式文档提供完整的英文和简体中文版本，章节、表格、示例与参考资料一一对应。代码、命令、API 标识符和来源网址保留原始拼写。远端历史归档保留来源语言，不会被当作中文译文。

需要确认工具版本、接口参数或使用条件时，沿条目中的来源链接查阅官方文档。
