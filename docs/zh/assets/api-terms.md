# 生成式 API 与模型边界

复用 AI 辅助游戏的资产前，先确定要分发什么。Long Wind 的[创作者署名记录](https://github.com/jbang2004/long-wind/blob/main/CREDITS.md)将 MIT 代码、Poly Haven 资产、Tripo 角色和 Mixamo 动画分开说明；作者明确要求不要单独提取并再分发后两者。因此，下载源码后，仍须逐文件判断能否复用。

为自己的发行版本，把每个角色、纹理、声音和动作文件与来源、适用条款及预定去向放在一起记录：打包游戏、可下载资产包，还是公开研究数据集。在文件离开原型前解决缺失的许可；开发可以先用占位资产继续。评估服务时，要区分私有集成测试、公开输出，以及用输出改进另一个模型。这些用途可能适用不同条款。

用下表找到对应产品与渠道，核对谁可以使用输出、提供商可以保留什么或用什么训练，以及文件如何保存。将实际协议或模型卡修订版与资产记录一同保留。

另请参阅[生成式工具补充研究](generative-tools.md)，了解目录卡片之外经过来源审阅的工具。

Luma Agents 与旧版 Dream Machine 使用不同的模型和请求模式。可续期的下载链接并不承诺无限期存储资产。同样，客户端轮询超时也不能证明远程任务已取消或已退款。
