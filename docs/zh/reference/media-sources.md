首页预览截取自项目作者发布的录像。下列署名将每个片段链接至其原始来源。

预览保留源画面的所有部分，包括原始游戏界面和输入/输出对比标签。六个主要片段仅经过片段选取、等比例缩放、帧率标准化（最高 30 fps）、H.264 编码、移除音轨，以及首帧 WebP 封面编码处理。方形画面和宽幅对比画面采用低调的衬底，而非裁切内容。下方图库在可行时使用原生画面比例。移动端对比变体还会按下文说明重新排列两个完整的源面板；不会裁剪、替换或生成任何场景内容。

## 交付与播放

每个片段及对应封面均位于 `website/public/media/showcase/`。[清单](../../../website/public/media/showcase/manifest.json) 记录原始 URL、源与输出尺寸、片段边界、大小及 SHA-256 校验和。六个主要视频片段合计 21.13 MB；移动端替代版本另占 2.05 MB，保留的 Holodeck 资源库片段另占 3.98 MB。所有随附 MP4 合计  **27.16 MB** （27,156,189 字节）。加上全部对应封面，完整的本地演示媒体包合计  **27.62 MB** 。视频均为无音轨的 H.264 MP4，并将 `moov` 盒置于 `mdat` 前，以支持渐进式播放。

进入页面时，只有选中的主视觉案例会挂载视频源。预览默认静音；手动暂停状态会跨案例和路线保留。启用减少动态效果或节省流量偏好时，首先显示真实首帧封面。离开屏幕、标签页隐藏、详情抽屉或导航叠加层打开，以及其他预览或影片播放器正在播放时，播放都会暂停。图库视频仅在指针表现出交互意图或明确点击时才挂载。未经优化的旧版远程视频仅支持点击播放。播放位置和时间取自实际播放中的媒体，而非装饰性的进度动画。

“观看完整演示”会打开无障碍播放器，使用原生控件，在原片有声音时播放声音，并载入作者托管的原始录像。这些完整影片和外部项目页面需要联网。2D 次要来源使用作者官方仓库的原始下载 URL，以避开较慢的 GitHub Pages 节点；项目页面仍作为署名来源。
