# GameMap 资源标志来源

在此查阅每项资源背后的组织、研究机构归属或维护者，以及随附标志的来源。

学校和研究机构标志表示已核实的作者机构归属，而非独占所有权或背书。对于合作研究，下方说明保留了标志选择理由及其他机构归属。官方项目标志仅标识其自身项目；第三方引擎工具不沿用引擎标志。没有可公开核实标志的独立项目仅显示维护者姓名。不以生成标志、通用图标、默认 identicon 或肖像替代。

原始图形以完整的宽高比和原色显示。宽幅文字标志获得更多展示空间。SVG 文件中的非可视 XML 声明和外部 DTD 头部会被移除；图形本身不作修改。文件从本地 <code>website/public/logos/</code> 提供，无需发起远程图像请求。标识注册表记录原始图片 URL、主要机构归属证据和 SHA-256 校验和。<code>website/public/icons/</code> 下的旧文件不用于资源标识；其随附许可证仍与这些文件一同保留。
