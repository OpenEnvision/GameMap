## 接口与观测边界

- 原生 API、编辑器脚本、运行时插件、CLI、HTTP/WebSocket、MCP、GUI 及文件交换具有不同状态和权限边界。社区 MCP 桥接不会继承底层引擎的每一项保证。
- 不能假定仅编辑器脚本存在于已交付运行时。无界面可能意味着没有窗口，但仍需要 GPU、图形 API 及已初始化渲染管线。
- 无障碍树、像素捕获及权威引擎状态是不同观测。屏幕坐标需要显示器/窗口/DPI/裁切上下文；点击回执不是动作完成信号。
- 文本、代码、图像、视频、音频、网格、材质、绑定、动画、场景、运行时状态及跟踪需要不同产物契约。渲染图像不能证明原生资源已保存，也不能证明依赖可在另一台机器上解析。
- 标签缺失是目录局限，不是上游工具缺少该功能的证据。排除候选前检查所链接来源及版本。

## 从已收集来源到可执行研究系统

下一步实现任务：

1. 将资源发现、归一化操作契约、本地适配器及运行时验证保持为独立状态。
2. 在真实环境中解析工单：软件/插件版本、模式、硬件、图形、身份验证、许可、预算及文件系统权限。
3. 分别识别逻辑资源、实际实现及单个会话/作业。注册表标识符不是活动对象句柄。
4. 保留带来源记录的原始产物、变换、结构化证据及面向模型的数据包。记录模型实际收到的内容。
5. 将修改限制在已声明的策略/程序组件中。记录工具与文件权限；不受限制的脚本执行不等同于受约束的语义 API。
6. 区分数据检查与可执行语义回归：单位、坐标系、陈旧世界状态、对象身份、异步完成、取消、恢复及冷启动重开。
7. 在声称来源搜索能够解析或执行能力链前，先评估检索及兼容性解释。
8. 使用留出任务、重复试验、重置策略及未触碰的最终评估集，比较有界测试框架候选。GEPA 或 Meta-Harness 接口不会自动提供游戏特定评估器。

此处发布的档案均未确立引擎适配器、环境解析器、执行锁文件、可信证据运行器、持续来源监测器或有效的自我改进循环。构建这些组件需要明确的目标环境及验收夹具。

## 实用目录查找

现有网站筛选器及可下载的 `data/resources.json` 是起点。对于仅本地来源搜索，下列命令使用当前仓库数据，不安装所列工具：

```sh
node --input-type=module -e '
import fs from "node:fs";
const rows = JSON.parse(fs.readFileSync("data/resources.json", "utf8"));
const terms = /cancel|recovery|asynchronous|accessibility|localization/i;
console.log(rows.filter(r => terms.test([r.name,r.summary,r.detail,...r.tags].join(" ")))
  .map(r => ({id:r.id, name:r.name, stages:r.stages, checked:r.verified, url:r.url})));
'
```

此词法搜索返回来源描述，而非可执行资格。使用档案补足操作层约束，并在具体环境测试前保留未知事项。
