# 设计系统（第一版）

已由[第二版](../v2/design-system.md)取代。本页记录第一版的视觉方向。

内置 ImageGen 概念图：`map-concept.png` 和 `library-concept.png`。这些图用作设计参考；网站通过 SVG/CSS/React 绘制地图、线条插画、控件和文字。

概念简报：面向 AI 游戏开发的高品质编辑式研究图谱。采用白色 214px 导航栏、米白色工作区、森林绿文字和黄绿色选中状态；包含六阶段连通式规划画布、右侧资源检查面板、分类发现、可搜索的编辑精选资源列表、书签和详情抽屉。使用原生文字与控件；不虚构指标。

设计令牌：工作区 #f6f5ef，导航 #fbfbf8，文字 #20322e，线条 #dedfd6，选中状态 #d5ee83，地图 #edf0e4。分类强调色为鼠尾草绿 #6e9d51、薰衣草紫 #9780d5、橙色 #ec965b、蓝色 #6b91d0、粉色 #cd85ad。

字体：主要界面使用 DM Sans，中文使用 Noto Sans SC，选定的展示词使用 Instrument Serif 斜体。外部字体不可用时，通过无衬线和衬线系统后备字体保持布局。

布局：桌面端采用固定的 65px 页头和 214px 导航栏；内容两侧留白为 36px。六个节点以 S 形路线相连，配有 279px 检查面板。宽度低于 1000px 时，地图改为单列。移动端导航变为抽屉，地图检查面板移至画布下方。资源行改为便于阅读的单列。

共享组件：Header、Sidebar、MapView、ResourceLibrary、ResourceDrawer、FieldNotes、AtlasArt。交互模型：维度标签页、可点击的阶段节点、上下文相关资源、查询/分类/类型/阶段/维度筛选、排序、资源深层链接、本地书签、Markdown 导出和键盘导航。

动效：180–500ms 的轻微入场及状态过渡；减少动态效果偏好会禁用过渡。不使用位图叠加层或图像染色；原始生成概念参考图保留于此，供审阅。
