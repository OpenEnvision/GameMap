# GameMap / World Studio — 视觉规范

当前参考图：overview-concept.png 和 library-concept.png，使用内置 ImageGen 创建。它们取代第一版视觉方向。界面仍使用原生 React/CSS/SVG；原创插画和官方项目预览作为独立素材。

配色：页面 #111214；侧栏 #161719；表面 #1a1b1e；边框 #303135；主要文字 #eeeae4；次要文字 #aaa7a2；弱化文字 #767773；强调色 #ff754e。采用真正的深色背景，不叠加紫色色调。选中控件使用暖橙色，并以克制的暖色层次表现抬升效果。首屏主视觉有明确的从左向右边缘渐隐效果，右侧保留图像原色。

字体：Space Grotesk，700 / 展示文字 64–80px；Manrope，400–700 / 界面文字 12–15px；英文正文使用 Manrope 及系统后备字体。高密度数据采用易读的 12–13px 正文和 15–16px 标题。移动端展示文字缩放至 40–49px，正文为 12–13px。移动端搜索输入框使用 16px 字号，避免聚焦时缩放。

外壳：210px 固定导航、66px 固定页头、26px 主内容两侧留白。使用 SVG 自定义几何地图标志。当前导航项带有橙色左侧线条和深暖色填充。所有导航均使用有意义的线性符号。品牌资源使用本地真实 SVG；没有品牌的论文/工具使用语义化矢量图形，而非字母组合标记。

概览：400px 电影感世界主视觉，文案为“构建你的下一个世界。”，附英文用途说明、探索地图和资源行动按钮。三张插画路线卡片用于选择 2D、3D 和 Code WM。六步骤深色交互地图配有真实资源检查面板。随后是真实且注明来源的项目图库、六个分类发现链接和方法说明。

资源库：宽敞的标题区和英文副标题、精选项目预览栏、搜索及列表/网格控件、六个分类标签页，以及可用的阶段/类型/维度/排序筛选。编辑精选行使用真实品牌和对应来源的预览；图库视图在没有真实预览时使用矢量标识。抽屉在有可用素材时展示真实预览，并包含来源署名、类型/年份、实际有来源依据的描述、主题、来源行动按钮和保存状态。

笔记：带插画的编辑式标题、四则编号概念笔记、以图像为主的 Code WM 说明，以及明确的状态/结构/渲染流水线。已保存合集沿用资源库的设计语言。

插画：/media/editorial/\* 为 AI 生成的原创编辑插画，并相应标注。/media/demos/\* 为作者/官方预览，每项均有来源/署名。绝不以想象的项目成果替代官方证据。不在静态图片上使用误导性的视频播放按钮。

动效：悬停时轻微缩放图像、橙色选中状态过渡、短促入场；减少动态效果偏好会禁用过渡。路线始终可通过键盘操作，移动端导航关闭时从无障碍树中隐藏，模态框内保持焦点约束。移动端路线节点采用易读的双列布局，检查面板堆叠于下方。

英文版：所有界面文案、目录内容、无障碍标签和可下载的读者指南均使用英文。移动端主视觉内容和来源署名自然排布，不共用固定的垂直槽位。根目录的 index.html 仍是生成的可直接打开预览；GitHub Pages 发布 dist/。
