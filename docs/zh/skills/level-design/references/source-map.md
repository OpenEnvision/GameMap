- 来源：[The Level Design Book](https://book.leveldesignbook.com/)。
- 阅读快照： **2026-10-16** 。
- 发现方式：[llms.txt](https://book.leveldesignbook.com/llms.txt)，并与 [sitemap-pages.xml](https://book.leveldesignbook.com/sitemap-pages.xml) 交叉核查。
- **已获取并阅读 94 个不重复的索引页面。** 规范化首页与 Markdown 后缀之后，站点地图与文档索引一致。
- 阅读范围：页面正文、表格、图注／替代文本、示例及页内技术清单。嵌入的图片／视频不等于实际观看媒体或游玩游戏；未对图像进行穷尽式视觉检查。
- 外部链接的文章、演讲、书籍、源码仓库、资源库和游戏， **不** 计为已经独立阅读、观看、审计或游玩。
- 临时来源缓存不包含在本技能中。本目录包含新措辞、精简分析、任务分流、检查清单与模板，而非来源语料全集。

## 如何理解覆盖情况

已查阅表中的页面；“正文”标记含有实质文本的页面。整本书仍在建设中，一些有实质内容的页面也包含 TODO。

“草稿”“简短”“提纲”和“占位”描述的是快照状态，不是对重要性的判断。本技能将草稿扩展为实用检查时，会将这些检查标为改编，而不是把缺失内容归于原作者。

原书作者的解读与预测，与已确立事实及实测结果保持区分。数值示例、工具版本、平台意见、价格和社区描述，在相关时需要核实当前情况。

## 改编边界

- **入口：** SKILL.md 包含任务分流与最简的证据驱动操作循环。
- **十二份专题参考：** 整合相关页面，同时保留重要分歧、类型假设与来源缺口。
- **三个模板：** 新组织的简报、试玩测试报告与评审结构。它们并非原书中的原始表格。
- **不暗中扩展来源：** 只有标题的案例研究不会变成完整分析；外部参考书目条目不会变成继承的证据。
- **不附带第三方资源或存档代码：** 尤其是独立许可的 MDL 材料。
- **权利与署名：** 参见 [LICENSE.md](../LICENSE.md)。改编说明材料采用 CC BY-NC-SA 4.0。

## 刷新流程

1. 重新获取索引与站点地图。
2. 比较新增、删除、重命名的 URL 与页面实质变化。
3. 阅读变化页面，包括权利声明与新完成章节。
4. 更新相关专题参考、来源状态标签与快照。
5. 验证内部链接、来源覆盖、前置元数据与任务分流。
6. 保持改编与来源主张、实际测试证据之间的可区分性。
