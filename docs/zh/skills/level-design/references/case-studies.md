# 研究关卡并迁移其中的关系

来源：[如何研究关卡](https://book.leveldesignbook.com/studies/overview)、[单人研究](https://book.leveldesignbook.com/studies/sp)、[Undead Burg](https://book.leveldesignbook.com/studies/sp/undead-burg)、[Assassins](https://book.leveldesignbook.com/studies/sp/assassins)、[多人研究](https://book.leveldesignbook.com/studies/mp)、[Chill Out](https://book.leveldesignbook.com/studies/mp/chill-out)、[现实世界研究](https://book.leveldesignbook.com/studies/irl)、[Disneyland](https://book.leveldesignbook.com/studies/irl/disneyland)。依据 CC BY-NC-SA 4.0 改编与重组。这些是对原书分析的解读，而非新记录的试玩测试。

## 1. 将关卡作为可玩的作品来研究

不要让研究始于、也止于一张俯视截图。

明确：

- 游戏／版本、模式、规则、玩家状态与相关机制。
- 可用证据是什么：直接游玩、录像、地图、编辑器数据，还是作者分析。
- 促成研究的问题是什么。
- 哪些观察属于你，哪些来自来源。

有用的研究轮次：

1. 不带预设论点地游玩或观察，以发现意外。
2. 重建路线、高度、门槛、资源、遭遇与状态。
3. 聚焦一种关系，重复研究。
4. 形成解读并寻找反例。
5. 识别迁移需要哪些假设。

无法直接游玩时，要如实说明。细读仍可能有用，无需假装它是实证用户研究。

## 2. Undead Burg — Dark Souls

**来源状态：** 内容充实，但明确尚未完成。

### 核心解读

文章将一个相对线性的城堡区域视为探索模式的教学。分支、高差、危险、战利品、重复空间与捷径，教玩家如何阅读这款游戏。

有用的关系：

- 可见或隐含的目的地鼓励调查。
- 可选绕行考验好奇心，并显露信息或奖励。
- 遭遇与狭窄流线、远程压力和接近方向相互作用。
- 返回可辨认地点，使最初令人困惑的网络变成习得的地理知识。
- 篝火与后续连接改变了重复路线的成本与含义。

### 可迁移的问题

一段短区域能否教会玩家这款游戏如何隐藏和重新连接空间，而无需让他们背诵任意指令？

### 原型改编

构建一条必经路线、一条清晰可读但可选的绕路，以及一条返回连接。布置威胁，让观察和接近方式真正重要。测试不熟悉关卡的玩家是否：

- 注意到探索的可能。
- 区分推进与绕行。
- 认出返回连接。
- 在重试时使用已学知识。

这是一种改编，不是文章的完整图解，也不是复制该关卡的配方。

### 不要盲目迁移

Dark Souls 的镜头、战斗动作承诺、死亡、资源回收与重复通行支撑这些关系。拥有即时无约束移动、没有重试成本或战斗可读性不同的游戏，可能需要另一种结构。

## 3. Assassins — Thief: The Dark Project

**来源状态：** 有实质内容的细读。

### 核心解读

任务随着时间改变玩家与 City 的关系：最初熟悉的公共环境，变成跟踪目标、进入私人领地，以及后来在危险中穿行的场所。

文章关联了：

- 赋予玩家调查目标的起始事件。
- 在 City 中跟踪刺客。
- 发现并潜入 Ramirez 的私人空间。
- 搜刮后返回，而环境的含义与威胁已经改变。

空间形态、通行权限、巡逻、可见性和顺序，同时支持潜行与对权力的解读：私人权威逐渐占据公共空间。

### 可迁移的问题

在变化条件下复用场所，能否产生新的活动与新的解读，而不只是节省制作工作？

### 原型改编

创建一条先用于观察、后来用于逃脱或谨慎返回的路线。改变部分通行条件、角色或知识，而不一定改变整个几何结构。

测试：

- 玩家能否理解发生了什么变化？
- 既有空间知识是否仍有用？
- 新威胁是否可读，而非任意出现？
- 返回是否支持预期含义，而不只是增加难度？

### 不要盲目迁移

光影潜行、守卫行为、移动和信息都很重要。常规战斗游戏无法仅靠复制宅邸平面图来重现该任务的关系。

## 4. Chill Out — Halo: Combat Evolved

**来源状态：** Andrew Yoder 撰写的充实多人分析。

### 核心解读

Chill Out 是一个紧凑、不对称的竞技场。文章从 Halo 的规则谈起，因为无法脱离移动、护盾、生命值、武器和拾取行为来评估几何。

有用的关系：

- 房间、走廊、高差与捷径构成密集流线网络。
- 武器与物品位置创造移动和争夺的理由。
- 重要位置提供优势，同时附带成本与弱点。
- 视觉区分和反复通行帮助玩家学习竞技场。
- 资源时机与控制权改变路线或房间在对局中的含义。

### 可迁移的问题

每个强势位置是否都参与了更广的信息、资源、暴露与机动性交换？

### 原型改编

使用由少量鲜明空间组成的小型不对称网络。赋予一个有价值的位置具体优势，再测试其通达、资源、视野、弱点与逃离。

测量相关接敌和轮转时间；观察控制权能否易手。不要凭对称或整洁平面图声称平衡。

### 不要盲目迁移

武器效能、护盾恢复、玩家速度和物品规则都可能逆转位置优势。让来源中特定数值主张始终对应确切游戏／版本，而不要把它们当作通用射击游戏度量。

## 5. Disneyland — California

**来源状态：** 有实质内容的现实世界研究。

### 核心解读

文章将主题化实体空间与类似游戏的空间组织联系起来，同时讨论文化与政治含义。

它讨论了：

- 设计者的实地研究与考察实践。
- 空间的分层与揭示。
- **诱引地标（Weenies）：** 引导游客继续前行的醒目远处景点或地标。
- **土堤（Berms）：** 组织并遮蔽环境的边界。
- **黑暗乘骑（Dark rides）：** 精心布置的顺序体验。
- 呈现、控制、历史与文化再现之间的冲突。

### 可迁移的问题

地标、隐藏的过渡、边界与编排序列如何组织期待——又将谁的世界观常态化？

### 原型改编

构建一段进路，使目的地在路线完全显露前就可见。在保持定向的同时，改变围合与显露。测试好奇心与理解能否并存。

### 不要盲目迁移

游客的身体、疲劳、排队、天气、无障碍需求、金钱和社会条件，都不同于游戏化身。不要把对受控商业环境的分析，变成适用于所有公共空间或游戏、未经批判的理想。

## 7. 迁移矩阵

借用模式时，使用这一改编：

| 字段         | 记录                                   |
| ------------ | -------------------------------------- |
| 观察到的关系 | 什么将行动、空间、信息与后果联系起来？ |
| 来源证据     | 直接游玩、作者分析、录像或地图         |
| 支撑规则     | 镜头、移动、战斗、持久化、资源、受众   |
| 预期效果     | 这种关系似乎实现了什么                 |
| 替代解释     | 还有什么可能产生该效果                 |
| 目标差异     | 哪些支撑条件缺失或改变了               |
| 小型原型     | 对这种关系的最小重建                   |
| 测试         | 能够支持或质疑迁移的可观察行为         |

成功的迁移是在新条件下保留有用关系，不需要复制来源的主题、轮廓、房间数量或声誉。

### 已填提案：认出返程连接

下面这份 GameMap 提案将上面的 Undead Burg 改编发展成可测试的微型场景。它是等待搭建与测试的设计，不是对 Dark Souls 的新观察，也不是已经完成的原型报告。

```text
A ---- B ---- C
|            |
+----- G ----+
```

其中 A 是起始庭院，B 是去程上易于识别的地标，C 是目标位置。G 是只能先从 C 一侧打开的捷径门。取得目标物后，任务是返回 A。使用现有移动与交互机制，并让地标从返程入口可见。

搭建时用实际角色控制方式检查路线成本：图上只画成一条边的连接，未必走起来更快。若 G 没有缩短返程，应调整空间，或将其描述为备选路线，而不是声称它带来了捷径收益。

| 迁移字段 | 已填提案                                                                         |
| -------- | -------------------------------------------------------------------------------- |
| 关系     | 打开连接，将去程转成可辨认且更短的返程                                           |
| 所用证据 | 原书对 Undead Burg 的分析，尤其是重复空间与捷径；本例不声称进行过直接游玩        |
| 支撑规则 | 持久保留的门状态、返程目标、可区分的地点，以及无法绕过门的角色控制方式           |
| 预期效果 | 玩家认出 A，并理解 G 改变了路线网络                                              |
| 替代解释 | 目标箭头或明确指令引导玩家穿过 G，却未产生地点识别                               |
| 目标差异 | 微型场景没有战斗、死亡或资源回收成本；它测试方向认知，而非完整的 Dark Souls 体验 |
| 小型原型 | 三个空间和一扇可用的门；不同修订使用相同的标记与指令设置                         |
| 测试     | 打开 G 后，观察返程选择，在解释捷径之前请玩家指出自己到了哪里                    |

分别记录 **发生了什么** 和 **它可能意味着什么**。走过 G 说明使用了路线；正确认出 A 或解释新连接，才为地点识别提供证据。如果玩家是在被告知后才穿过 G，路线在技术上可用，但预期学习仍缺乏证据支持。

每次尝试都记录构建版本、初始状态、此前是否见过布局、给出的提示或帮助、所走路线，以及能定位观察的录像时间或截图。如果玩家把 A 误认为新庭院，修改可辨认的地标或返程框景，再请不熟悉该修订的人测试。不要将记住测试路线算作独立的首次体验证据。

AI 评估还必须说明观察与行动接口。获得完整房间图的玩家与依靠渲染图像导航的玩家，拥有不同证据。判断 AI 生成的布局是否传达空间关系时，应分别保留这些结果。
