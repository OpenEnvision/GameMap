# 布局、流动、垂直性、关键路径与门槛

来源：[布局](https://book.leveldesignbook.com/process/layout)、[流动](https://book.leveldesignbook.com/process/layout/flow)、[流线](https://book.leveldesignbook.com/process/layout/flow/circulation)、[垂直性](https://book.leveldesignbook.com/process/layout/flow/verticality)、[关键路径](https://book.leveldesignbook.com/process/layout/criticalpath)、[空间构思图](https://book.leveldesignbook.com/process/layout/parti)、[类型学](https://book.leveldesignbook.com/process/layout/typology)、[门槛](https://book.leveldesignbook.com/process/layout/typology/gates)。依据 CC BY-NC-SA 4.0 改编与重组。

## 1. 布局描述关系

“布局”既可以指关卡结构，也可以指表现它的图纸。图纸支持对连接、活动与约束的讨论，却不能证明 3D 体验能够成立。

关系尚不确定时，从节点图开始：

- 节点代表活动、重要地点或空间状态。
- 边表示方向、前置条件与行进成本。
- 标出起点、目标、必经流程、分支、返回与出口。

尺寸变得重要时，转向平面图和剖面图：

- 标注高程、坡道、楼梯、落差、桥梁与隧道。
- 区分视线与可通行连接。
- 区分单向落差、双向通道与可解锁捷径。
- 记录入口朝向与重要视野；玩家并不总是面向图纸上方。

**空间构思图（parti）** 是组织空间思路的简明示意，不是完整平面图。来源页面很简短，不要将一套复杂方法论归于它。

## 2. 流动与流线

**流动** 关注随时间变化的移动、注意力、战斗与活动。 **流线** 聚焦路线与连接如何支持移动。平面图上一条顺滑的线，无法证明二者中的任何一个。

在每个过渡处询问：

- 为什么来到这里，什么促成下一步行动？
- 通道是否支持移动、转向、镜头行为和相关战斗？
- 出口是否在有用的时机显露？
- 这是有意义的停顿，还是没有信息的停滞？
- 反向行进、重试、追逐或多名玩家同时通过时，是否仍然有效？

### 实用模式词汇

| 模式      | 适用于            | 常见风险             |
| ------- | -------------- | ---------------- |
| 线性序列    | 清晰的引入与协同事件     | 单调，或原样折返         |
| 分支后汇合   | 在可控制作成本下提供局部选择 | 选择仅有表面差异，或漏掉关键信息 |
| 环路      | 复用、辨认、追逐与包抄    | 漫无方向地绕圈          |
| 枢纽与辐射支路 | 多个目标及易辨认的返回点   | 重复往返             |
| 网络      | 多人轮转与多种解法      | 认知过载，或一条路线占据绝对优势 |
| 捷径／单向返回 | 降低重试成本并揭示空间关系  | 未被认出的连接，或软锁      |

这是一种实用综合整理，不是来源规定的六类分类法。

## 3. 让垂直性改变一种关系

楼层更多并不自动更好。高度可以：

- 改变视线、暴露程度、射程与战斗优先级。
- 建立俯瞰点、隐蔽处、地标和未来目的地。
- 创造单向过渡，或使分支回到熟悉地面。
- 叠置空间，揭示平面路线无法呈现的连接。

代价包括楼层识别、镜头控制、瞄准角度、坠落恢复、AI 导航，以及高差过渡的可通达性。

检查：

1. 从入口镜头能否注意到上／下层空间？
2. 可见空间是否可达？若不可达，是否会错误暗示存在路线？
3. 玩家能在哪里改变高度，付出什么成本？
4. 掉落后能否恢复？重试成本是否符合预期体验？
5. 强势高位由什么制衡：到达成本、暴露、资源、侧袭路线，还是难以撤离？

## 4. 关键路径不是唯一“正确”路线

**关键路径** 标识完成关卡所需的核心推进过程。它有助于核对前置条件、关键信息、资源、时机和重试，并不要求始终突出显示每个必到目的地。

- 识别必需行动和实际依赖，而不只是偏爱的路线。
- 区分首次通行、返回通行与捷径开启后的通行。
- 赋予分支功能：奖励、信息、练习、节奏变化或对世界的理解。
- 探索可以有意隐藏路线。应测试玩家是否理解自己在调查什么，而不是是否立即沿预设线路前进。
- 对多人、系统性与开放世界关卡，若单一路径会误导，应使用目标网络、主要轮转或局部任务。

设计者知道解法，并不能证明初次游玩的玩家可以推断出它。

## 5. 类型学：借用可辨认的空间组织

**类型学** 考察反复出现的空间类型：住宅、办公室、庭院、防御工事、商店等。

使用方式：

1. 调查用途、使用者、公共／私密关系和流线。
2. 找出受众可能认识的惯例。
3. 按机制调整连接、净空、入口、视线与高度。
4. 保留足够的可辨认结构，同时不牺牲操控或可读性。

不要混淆建筑风格与功能组织。一种类型并不是脱离地点、历史和社会关系的永恒模板。

## 6. 门槛使通行附带条件

- **硬门槛：** 通过需要钥匙、开关、能力或状态。
- **软门槛：** 可以通过，但风险、技巧要求、危险或资源成本会劝退玩家。
- **捷径：** 通常从远端解锁，以减少后续行进与重试成本。

明确：

- 阻挡了什么，为什么？
- 在哪里传达阻挡状态？
- 什么能解锁，玩家如何理解该条件？
- 失败、反复交互、离开和返回时会发生什么？
- 解锁如何影响路线、节奏、敌人和存档状态？

需要多把钥匙的锁应让数量清晰可读，而不是让玩家反复猜测还缺什么。

软门槛不只是一个强得压倒性的敌人。应测试玩家能否评估风险、撤退，并理解什么可能让未来的尝试有所不同。

## 布局走查

走过主路线，再反向走，探索分支，然后利用重生和捷径重复。记录：

- 位置、目标、可见出口和可用能力。
- 什么在吸引或排斥注意力与移动。
- 行进、等待和战斗成本。
- 确切的困惑点，以及促使某条路线占优的诱因。

将图纸落实为可玩的白盒。整洁的俯视平面图并不是验收证据。
