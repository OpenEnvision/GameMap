# 生成任务、产物交付与资产获取

## Replicate 文件获取与终态核算

于 2026-10-18 核查官方滚动更新文档；未执行任何预测任务、SDK、经身份验证的请求、文件下载或 webhook。[创建指南](https://replicate.com/docs/topics/predictions/create-a-prediction)区分通过 Prefer: wait 进行的 HTTP 等待与 Cancel-After 取消截止期限。未完成的同步响应不能确立远程取消。部分 JSON 示例使用 successful，而轮询正文及[生命周期参考](https://replicate.com/docs/topics/predictions/lifecycle)使用 succeeded；canceled 和 aborted 也是文档规定的结果。不要将简化的成功/失败循环用作完整状态机。

[文件输出指南](https://replicate.com/docs/topics/predictions/output-files)将 FileOutput 默认行为归于 1.0.0 版客户端库，同时记录了可选的返回 URL 行为。Python 字节读取器/迭代器与 JavaScript 流仍需完成持久化。未核查确切的当前 SDK 或已安装 SDK。其迁移建议针对 FileOutput 移除手动 Authorization 处理，而 [HTTP 参考](https://replicate.com/docs/reference/http)讨论直接文件 URL 授权。这些涉及不同的访问路径，并不能据此认定存在矛盾；此处未厘清直接下载要求及 SDK 处理。绝不要根据通用示例向输出主机转发服务凭据。

**拟议验收方式，尚未实现：** 将每个可用输出与角色/索引、字节/哈希、预测任务/模型/版本标识及保留的输入/日志一并归档；随后单独核对执行终态与费用核算。文件句柄或仍存在的预测任务 ID 都不是持久产物。提供商时序指标不是最终账单。[保留政策](https://replicate.com/docs/topics/predictions/data-retention)区分 API 与网页预测任务；确切的保留计时起点、续期及移除后恢复仍未核实。

未来测试夹具应区分处理中文件已可用、终态成功且文件已归档、数据移除后的成功、截断副本，以及同步等待到期但随后完成等情形。其中任何一种都不会自动授权再次付费提交。在选择前冻结候选字节与来源记录，将获取失败保留在分母中，并要求独立的目标引擎验收。输出权利、可复现性及端点特定费用仍未解决。

## ComfyUI：队列、执行事件与文件是独立接口

[路由文档](https://docs.comfy.org/development/comfyui-server/comms_routes)描述验证与入队；[执行消息](https://docs.comfy.org/development/comfyui-server/comms_messages)区分某个 prompt 的成功、错误与中断。executed 消息是 UI 更新，并非通用的整图成功信号。

在[已检查的服务器修订版](https://github.com/Comfy-Org/ComfyUI/blob/c06bf5f569d268b80076e5f44126f87cdf835869/server.py)中，调用者选定的 UUID 会在入队前不经重复 ID 检查而被接受。定向取消路径处理排队中/运行中的工作，并核查运行任务标识；已结束或未知 ID 返回 cancelled:false。这是源码快照，而非最低受支持版本。它不能证明外部服务请求或自定义节点会在中断时停止或退款。

[同一修订版的图像示例](https://github.com/Comfy-Org/ComfyUI/blob/c06bf5f569d268b80076e5f44126f87cdf835869/script_examples/websockets_api_example.py)通过 /view 解析历史输出描述符；二进制 WebSocket 数据是预览证据。其图像描述符并未定义所有视频/音频/自定义节点输出模式。

**拟议测试夹具：** 在提交已接受后断开客户端，不重新提交而核对队列/历史记录，纳入缓存节点和失败的输出节点，并将预期输出角色与已归档字节进行比较。分别记录自定义节点与检查点修订版。重启持久性及外部副作用回滚仍未知；共享工作进程的全局中断不能替代任务范围控制。

### 测试运行时播放之前，先捕获 Wwise 创作端 SoundBank

对于  **Wwise SDK 2024.1.9.8920** ，[`ak.wwise.core.soundbank.generate`](https://www.audiokinetic.com/en/public-library/2024.1.9_8920/?id=ak_wwise_core_soundbank_generate.html\&source=SDK) 是同步调用。输入选择用户定义的 SoundBank、平台和语言。空的音库列表会生成所有用户定义音库；所有自动定义音库都会生成，不受该列表影响。缺少平台/语言列表时，默认扩展至所有平台/语言；`skipLanguages=true` 会抑制本地化 SoundBank 的生成。`writeToDisk` 默认为 false：不写入磁盘时，需订阅 `ak.wwise.core.soundbank.generated` 以获取音库结构信息和 base64 音库数据。调用结果包含生成日志，而非运行时加载或播放结果。WwiseConsole 中这些日志为空。错误严重程度影响操作完整性；致命错误会阻止完成。`clearAudioFileCache` 会清除所有平台的整个音频缓存，即使生成时只选择了较少平台也是如此。

不要将 [`ak.wwise.core.soundbank.generationDone`](https://www.audiokinetic.com/en/public-library/2024.1.9_8920/?id=ak_wwise_core_soundbank_generationdone.html\&source=SDK) 用作唯一完成信号。同版本参考说明，此通知仅在 SoundBank 已生成时发出，不能可靠地判断 `generate` 是否完成。其公布字段包括生成日志以及已弃用的 `error` 字段；文档要求调用者改为检查 `logs`。未出现已弃用的错误字段不能替代这项检查。WwiseConsole 在该通知中也返回空日志。

**拟议测试框架关卡，而非上游保证。** 生成前记录创作端版本/项目修订版，以及包含 `skipLanguages` 的显式音库/平台/语言清单。在发出不写盘请求前建立 generated 主题订阅；保留收到的载荷及其哈希，或在启用磁盘输出时核验所请求的文件。分别跟踪同步调用结果、通知及捕获输出的覆盖情况；审查诊断信息，而非将空的 WwiseConsole 日志当作通过验证。检查实际输出覆盖情况，而非假定所请求的用户音库列表就是完整生成集合。将创作端生成、捕获产物的持久化、原生音库加载及事件执行视为独立关卡。本说明既不能确立断线后的通知重放，也不能确立超时取消、重试幂等性或回滚。如果接收情况不确定，应保留证据，并在重试前检查输出。清除缓存需要单独授权其范围；它不是无害的修复开关。

**尚未实现的测试夹具：** 所选用户音库加一个自动定义音库；省略语言/平台列表；不写盘生成且遗漏通知；有调用结果但未收到 `generationDone`；生成诊断；WwiseConsole 空日志行为。不能从本文档推出任何引擎集成、授权资格、再分发或可听成功的主张。
