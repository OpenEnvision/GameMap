# Luanti game source studies

Primary sources reviewed on 2026-10-22. Three Lua games demonstrate survival/resource processing, world-based crafting and machines, and an authored platform adventure. READMEs, gameplay code, release information and code/content terms were inspected; no game was installed, built or playtested.

[VoxeLibre](https://github.com/VoxeLibre/VoxeLibre/blob/master/README.md) is the renamed MineClone 2 project. [Mineclonia](https://codeberg.org/mineclonia/mineclonia/src/branch/main/README.md) is a separate fork that emphasizes stability, multiplayer performance and feature implementation. This guide selects Mineclonia alongside the mechanically different NodeCore and Glitch; it does not count MineClone 2 and VoxeLibre as additional games.

## Mineclonia — survival, crafting and building

- **Repository / status:** [mineclonia/mineclonia](https://codeberg.org/mineclonia/mineclonia), `main`. A playable beta with published [0.124.1 release](https://codeberg.org/mineclonia/mineclonia/releases/tag/0.124.1), supporting a substantial survival loop while some planned features remain unfinished.
- **Gameplay:** Gather wood, make tools and a workbench, then advance through mining, farming, smelting, equipment and construction while managing hunger and enemies. Creative mode supports unrestricted building; both single-player and multiplayer worlds are available.
- **Run:** The [README](https://codeberg.org/mineclonia/mineclonia/src/branch/main/README.md#installation) and [game.conf](https://codeberg.org/mineclonia/mineclonia/src/branch/main/game.conf) require Luanti 5.10 or newer stable releases. Install [Mineclonia](https://content.luanti.org/packages/ryvnf/mineclonia/) through Luanti's Content tab, or place the source directory inside the user-data `games/` directory as documented, then select the game when creating a world.
- **Useful source:** [mcl_farming/soil.lua](https://codeberg.org/mineclonia/mineclonia/src/branch/main/mods/ITEMS/mcl_farming/soil.lua) changes soil moisture using node state, nearby water and weather. [mcl_furnaces/init.lua](https://codeberg.org/mineclonia/mineclonia/src/branch/main/mods/ITEMS/mcl_furnaces/init.lua), especially `get_timer_function`, coordinates remaining fuel, recipe time, input/output inventories and active-node transitions. Useful for reading resource-processing systems in a persistent voxel world.
- **License:** [LEGAL.md](https://codeberg.org/mineclonia/mineclonia/src/branch/main/LEGAL.md) identifies GPL-3.0-or-later code, with additional license options for some modules. Pixel Perfection textures are mainly CC BY-SA 4.0, menu images CC0 and some models CC BY 4.0; other assets retain file/module notices, with unspecified media under CC BY-SA 3.0.

## NodeCore — crafting and machines inside the world

- **Repository / status:** [sztest/nodecore](https://gitlab.com/sztest/nodecore), `master`. An original game designed to provide a complete experience without extra mods. Its crafting, tools and machines are built around interactions with world blocks and items.
- **Gameplay:** Experiment to discover materials, craft tools and start fires, then combine optical logic and rotating mechanisms into machines. Progress depends on learning interactions and inventing combinations instead of using a conventional crafting menu. The [author's feature guide](https://gitlab.com/sztest/nodecore/-/blob/master/.cdb-header.md) describes its tutorial and discovery systems.
- **Run:** Install the [stable NodeCore package](https://content.luanti.org/packages/Warr1024/nodecore/) through Luanti's Content tab and create a NodeCore world. The [release notes](https://gitlab.com/sztest/nodecore/-/blob/master/.cdb-release.md) distinguish stable and ALPHA packages; repository `master` is labeled DEV. Current [game.conf](https://gitlab.com/sztest/nodecore/-/blob/master/game.conf) and [stable release metadata](https://content.luanti.org/api/packages/Warr1024/nodecore/releases/) specify a minimum engine version of 5.8.
- **Useful source:** [nc_stonework/adze.lua](https://gitlab.com/sztest/nodecore/-/blob/master/mods/nc_stonework/adze.lua) uses `register_craft` for recipes that apply gravel to existing tools in the world. [nc_fire/firestarting.lua](https://gitlab.com/sztest/nodecore/-/blob/master/mods/nc_fire/firestarting.lua) connects repeated strikes, tool properties and ignition. [nc_optics/prism.lua](https://gitlab.com/sztest/nodecore/-/blob/master/mods/nc_optics/prism.lua) changes output according to prism orientation and signals arriving at each face, providing a compact example of composable optical logic.
- **License:** Root [MIT license](https://gitlab.com/sztest/nodecore/-/blob/master/LICENSE); official [ContentDB metadata](https://content.luanti.org/api/packages/Warr1024/nodecore/) identifies both code and media as MIT.

## Glitch — authored platform exploration and ability progression

- **Repository / status:** [Wuzzy/Glitch](https://codeberg.org/Wuzzy/Glitch), `master`; [official site](https://wuzzy.codeberg.page/Glitch/). A complete single-player adventure that won the 2022 Minetest Game Jam and continues to receive maintenance releases.
- **Gameplay:** Play a lost bit in cyberspace, slide through authored areas, collect electrons, acquire movement abilities and unlock new regions. It includes a story and ending, using the voxel engine for a structured platform adventure.
- **Run:** Requires Luanti 5.6 or newer. The [README](https://codeberg.org/Wuzzy/Glitch/src/branch/master/README.md) recommends 5.10+, which is also required for translations. Install Glitch through the Content tab, choose it when creating a world, and use that world to store progress. Keep the default engine player-movement settings as instructed by the author, since the levels depend on them.
- **Useful source:** [glitch_abilities/special_moves.lua](https://codeberg.org/Wuzzy/Glitch/src/branch/master/mods/glitch_abilities/special_moves.lua) implements slide/dash movement, launch pads, cooldowns and availability feedback. [glitch_abilities/api.lua](https://codeberg.org/Wuzzy/Glitch/src/branch/master/mods/glitch_abilities/api.lua) stores abilities in player metadata and restores them on re-entry. [glitch_levels/gateways.lua](https://codeberg.org/Wuzzy/Glitch/src/branch/master/mods/glitch_levels/gateways.lua) gates areas by collected-electron count; [level definitions](https://codeberg.org/Wuzzy/Glitch/src/branch/master/mods/glitch_levels/levels.lua) include the final area and ending trigger.
- **License:** The [README's licensing section](https://codeberg.org/Wuzzy/Glitch/src/branch/master/README.md#licensing) separates GPL-3.0-or-later code from CC BY 4.0 media, including Visager's music.
