# Geometry, arcade survival and bullet-pattern game source

Primary sources reviewed on 2026-10-22. Four playable games show how unusual spaces, compact action sets and scripted projectile patterns become complete game loops. The guides use the reviewed default branches and distinguish their source requirements from packaged releases. No game was installed, built or playtested.

## HyperRogue — turn-based strategy in hyperbolic space

- **Repository / status:** [zenorogue/hyperrogue](https://github.com/zenorogue/hyperrogue), `master`; [README](https://github.com/zenorogue/hyperrogue/blob/master/README.md). A released, maintained roguelike in which players gather treasure, avoid or defeat monsters, and navigate lands with different movement rules. More treasure raises danger; magic orbs grant limited abilities. Players can pursue high scores or the Orb of Yendor objective.
- **Stack / learning value:** C++, SDL/OpenGL and custom non-Euclidean geometry/map systems. Adjacency, distance and map expansion change escape routes and tactics, making the geometry part of the rules rather than only the rendering.
- **Useful source:** [pcmove.cpp](https://github.com/zenorogue/hyperrogue/blob/master/pcmove.cpp), including `movepcto` and `pcmove`, connects movement, attacks, terrain and collection. [checkmove.cpp](https://github.com/zenorogue/hyperrogue/blob/master/checkmove.cpp) evaluates dangerous actions using a chess-like check system. [cell.cpp](https://github.com/zenorogue/hyperrogue/blob/master/cell.cpp) shows cell adjacency generation and distance queries.
- **Play / build:** The [author's itch.io page](https://zenorogue.itch.io/hyperrogue) provides free Windows/macOS downloads and source, with Android and paid-edition details linked separately. The README's Linux/macOS build route uses make, SDL 1.2 libraries, GLEW and libpng; its example command is `HYPERROGUE_USE_GLEW=1 HYPERROGUE_USE_PNG=1 make`.
- **License:** [GPL-2.0 code](https://github.com/zenorogue/hyperrogue/blob/master/COPYING); [music](https://github.com/zenorogue/hyperrogue/blob/master/hyperrogue-music.txt) is CC BY-SA 3.0. [Sound credits](https://github.com/zenorogue/hyperrogue/blob/master/sounds/credits.txt) and bundled font notices record their separate terms.

## Marble Marcher — timed traversal over changing fractals

- **Repository / status:** [HackerPoet/MarbleMarcher](https://github.com/HackerPoet/MarbleMarcher), `master`, by CodeParade. The [README](https://github.com/HackerPoet/MarbleMarcher/blob/master/README.md) calls it a game demo, while the author lists the 24-level release as a finished short experimental game. The original is no longer under major development; the author points to Community Edition for further work.
- **Gameplay / stack:** Roll a marble across changing 3D fractal surfaces to reach a flag quickly, avoiding falls and crushing geometry. C++11, SFML 2.5, Eigen 3.3, GLSL and CMake support custom fractal physics and ray-marching rendering.
- **Useful source:** [Scene.cpp](https://github.com/HackerPoet/MarbleMarcher/blob/master/src/Scene.cpp), especially `UpdateMarble`, `DE` and `MarbleCollision`, combines gravity, input, distance estimation, collision and crushing. [Level.cpp](https://github.com/HackerPoet/MarbleMarcher/blob/master/src/Level.cpp) defines level/fractal parameters, while [frag.glsl](https://github.com/HackerPoet/MarbleMarcher/blob/master/assets/frag.glsl) renders the procedural world. Useful for seeing the same geometry drive both image generation and playable collision.
- **Play / build:** The [author's itch.io page](https://codeparade.itch.io/marblemarcher) provides a Windows build. For source builds, follow [CMakeLists.txt](https://github.com/HackerPoet/MarbleMarcher/blob/master/CMakeLists.txt) with the SFML 2.5 series and Eigen; the runtime working directory must contain `assets/`. The author notes the GPU demands of its rendering.
- **License:** [GPL-2.0](https://github.com/HackerPoet/MarbleMarcher/blob/master/LICENSE). Game assets are present; bundled fonts also include [OFL](https://github.com/HackerPoet/MarbleMarcher/blob/master/assets/OFL.txt) and [CC BY-SA font terms](https://github.com/HackerPoet/MarbleMarcher/blob/master/assets/LICENSE.txt).

## Open Hexagon — circular arcade survival and Lua level patterns

- **Repository / status:** [vittorioromeo/SSVOpenHexagon](https://github.com/vittorioromeo/SSVOpenHexagon), `master`; [README](https://github.com/vittorioromeo/SSVOpenHexagon/blob/master/README.md). A released arcade survival game inspired by Super Hexagon. Rotate around the center, slow down for precise movement or swap to the opposite side, and survive patterns of approaching polygon walls. It uses rhythmic movement and spatial recognition rather than conventional note-judgment rhythm mechanics.
- **Stack:** The current [CMake configuration](https://github.com/vittorioromeo/SSVOpenHexagon/blob/master/CMakeLists.txt) uses C++20, SFML and LuaJIT; Lua exposes level-pattern design.
- **Useful source:** [CPlayer.cpp](https://github.com/vittorioromeo/SSVOpenHexagon/blob/master/src/SSVOpenHexagon/Components/CPlayer.cpp) implements circular movement, focus slowdown, 180-degree swapping and collisions. [CWall.cpp](https://github.com/vittorioromeo/SSVOpenHexagon/blob/master/src/SSVOpenHexagon/Components/CWall.cpp) handles inward and curved wall motion. [pointless.lua](https://github.com/vittorioromeo/SSVOpenHexagon/blob/master/_RELEASE/Packs/cube/Scripts/Levels/pointless.lua) demonstrates pattern queues, escalating difficulty, pulse and beat parameters. Useful for reading how a small move set supports demanding, scriptable levels.
- **Play / build:** The [Steam release](https://store.steampowered.com/app/1358090/Open_Hexagon/) includes its game and music content. The [official build wiki](https://github.com/vittorioromeo/SSVOpenHexagon/wiki/Building-Instructions) documents cloning with submodules and Windows MSYS2/Linux CMake builds. It explains copying music from the Steam `Packs` directory; the source package does not supply all commercial music.
- **License:** [AFL-3.0 code](https://github.com/vittorioromeo/SSVOpenHexagon/blob/master/LICENSE). The [audio asset notice](https://github.com/vittorioromeo/SSVOpenHexagon/blob/master/_RELEASE/Assets/Open%20Hexagon%20Assets%20License.txt) restricts the listed sound effects to Open Hexagon. Treat the game code and audio permissions separately.

## Taisei — scripted bullet patterns and risk-based scoring

- **Repository / status:** [taisei-project/taisei](https://github.com/taisei-project/taisei), `master`; [README](https://github.com/taisei-project/taisei/blob/master/README.rst). A complete unofficial Touhou fan game with original story, music, art, mechanics and code. Six stages, boss spell cards, grazing, bombs and Power Surge support full-game and practice play.
- **Stack:** The current development tree uses C11, SDL3, OpenGL and Meson. Use the documentation matching the selected source/release version when preparing dependencies.
- **Useful source:** [player.c](https://github.com/taisei-project/taisei/blob/master/src/player.c) handles precise movement, bombs, grazing and Power Surge resources. [crystal_rain.c](https://github.com/taisei-project/taisei/blob/master/src/stages/stage1/spells/crystal_rain.c) combines task/wait sequences, difficulty parameters and projectile motion into a boss attack. [GAME.rst](https://github.com/taisei-project/taisei/blob/master/doc/GAME.rst) explains the resulting player decisions. Useful for studying readable bullet choreography and risk/reward scoring.
- **Play / build:** The reviewed stable download is [v1.4.6](https://github.com/taisei-project/taisei/releases/tag/v1.4.6); the README also links an [experimental browser version](https://play.taisei-project.org/). Current [BUILD.rst](https://github.com/taisei-project/taisei/blob/master/doc/BUILD.rst) requires recursive submodules, Meson 1.8+ and SDL3 3.2+, then `meson setup build/`, `meson compile -C build/` and `meson install -C build/`. Use a recursive clone or the complete release source archive; the ordinary GitHub ZIP omits needed submodules.
- **License:** [COPYING.txt](https://github.com/taisei-project/taisei/blob/master/COPYING.txt) identifies MIT code, CC BY 4.0 original music/character portraits and separate background-photo credits. The project remains an unofficial derivative fan game; the code license does not grant rights to the underlying Touhou characters.

This repository supplement is linked from the README; it is not part of the exported website catalog.
