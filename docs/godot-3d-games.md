# Godot 3D games

Study native Godot game projects through their scenes, gameplay scripts, and available releases. Start with tactics, first-person exploration, train driving, or circuit racing rather than an engine template. Other options include party minigames, rebound platforming, river-tile strategy, and downhill sledding.

This repository research supplement is not yet included in GameMap’s exported website cards or search. The projects below use Godot scenes with GDScript or the explicitly labeled Mono/C# edition; the cited setup evidence does not require a custom engine fork. That is not a claim that each source checkout runs unchanged in today's Godot.

## Tanks of Freedom II

[P1X’s Tanks of Freedom II](https://github.com/P1X-in/tanks-of-freedom-ii) is an isometric strategy game with up to four armies, an AI campaign, hot-seat battles, and an editor for making and sharing maps. Its voxel presentation is implemented with real 3D scenes rather than a 2D board labeled as 3D.

- **Play or obtain a build:** the [creator’s game page](https://czlowiekimadlo.itch.io/tanks-of-freedom-ii) lists Windows and Linux downloads. Those listings were read, not downloaded or played.
- **Open the project:** the [pinned project file](https://github.com/P1X-in/tanks-of-freedom-ii/blob/dbe629ea05691599dde4fd65ab9a13b78a4ccfe1/project.godot) declares Godot 4.4 and starts at the main menu. The [README](https://github.com/P1X-in/tanks-of-freedom-ii/blob/dbe629ea05691599dde4fd65ab9a13b78a4ccfe1/README.md) still says 4.2 or newer; use the inspected project’s version as the starting point rather than treating that older minimum as tested compatibility.
- **Inspect 3D implementation:** the [unit scene](https://github.com/P1X-in/tanks-of-freedom-ii/blob/dbe629ea05691599dde4fd65ab9a13b78a4ccfe1/scenes/tiles/units/unit.tscn) contains `Node3D`, meshes, lighting, and 3D particles.
- **Reuse limits:** [license terms](https://github.com/P1X-in/tanks-of-freedom-ii/blob/dbe629ea05691599dde4fd65ab9a13b78a4ccfe1/LICENSE.md) apply MIT to code and graphical assets except stated exclusions. QmYaan’s audio is CC BY-SA 4.0 and reduz’s audio is CC BY 4.0; control icons are CC0 and fonts have separate licenses. Media under `docs/` is proprietary, not a reusable screenshot pack.

## Meteorite

[Bauxitedev’s Meteorite](https://github.com/Bauxitedev/meteorite) is a released first-person metroidvania made for LOWREZJAM 2018. Explore a facility, acquire weapon and movement upgrades, pass earlier obstacles, and confront enemies and a boss.

- **Play or obtain a build:** the [creator’s game page](https://bauxite.itch.io/meteorite) lists Windows, Linux, and macOS downloads. A GitHub release tag is not being presented as a prepared binary download.
- **Open the project:** follow the [pinned README’s compatibility and font instructions](https://github.com/Bauxitedev/meteorite/blob/1cf2ffd8cc86242d9641cba1792a4c5c39e1139a/README.md). It specifies Godot 3.0.4 and warns that newer versions can break the game. The non-redistributable `uni0553-webfont.ttf` is omitted from the repository and must be obtained separately; without it, text is missing. The historical font-download endpoint was not validated.
- **Inspect 3D implementation:** the [project](https://github.com/Bauxitedev/meteorite/blob/1cf2ffd8cc86242d9641cba1792a4c5c39e1139a/project.godot), [player scene](https://github.com/Bauxitedev/meteorite/blob/1cf2ffd8cc86242d9641cba1792a4c5c39e1139a/scenes/player.tscn), and [player script](https://github.com/Bauxitedev/meteorite/blob/1cf2ffd8cc86242d9641cba1792a4c5c39e1139a/scripts/player.gd) connect a 3D body and camera to movement, jumping, shooting, damage, saves, and an ending sequence.
- **Reuse limits:** the README licenses `scripts/` and `materials/shaders/` under MIT and the remaining included assets under CC BY-SA 4.0. The omitted font is separate; those licenses do not supply it.

## Libre TrainSim

[Libre TrainSim](https://github.com/Libre-TrainSim/Libre-TrainSim), started by Jean28518 and maintained by the Libre TrainSim contributors, is a train-driving simulator. Its project includes cab controls, acceleration and braking, rail geometry, signals, and route scenes, making it useful for studying a larger simulation rather than a single vehicle controller.

- **Choose a release or development source:** [v0.8.1](https://github.com/Libre-TrainSim/Libre-TrainSim/releases/tag/v0.8.1) is a published maintenance release. The inspected source identifies itself as `v0.9.beta1`; it is not asserted to match that release. The [v0.9.beta1 release notes](https://github.com/Libre-TrainSim/Libre-TrainSim/releases/tag/v0.9.beta1) limit that beta to tutorial routes while other tracks await updates.
- **Open the project:** import [`src/project.godot`](https://github.com/Libre-TrainSim/Libre-TrainSim/blob/1e22e0eefe3d7e7dea8f21b695cc55e659ef4ccb/src/project.godot), not an assumed root project. The [pinned export workflow](https://github.com/Libre-TrainSim/Libre-TrainSim/blob/1e22e0eefe3d7e7dea8f21b695cc55e659ef4ccb/.github/workflows/export.yml) selects Godot 3.5.2; this is stronger version evidence than the README’s unqualified “latest version” instruction.
- **Inspect 3D implementation:** the [tutorial route scene](https://github.com/Libre-TrainSim/Libre-TrainSim/blob/1e22e0eefe3d7e7dea8f21b695cc55e659ef4ccb/src/Worlds/Tutorials/Tutorials.tscn) contains a `Spatial` world, rails, signals, environmental lighting, and player placement. [Project notes](https://github.com/Libre-TrainSim/Libre-TrainSim/blob/1e22e0eefe3d7e7dea8f21b695cc55e659ef4ccb/src/README.gd) distinguish implemented systems from future ideas.
- **Reuse limits:** the [root license](https://github.com/Libre-TrainSim/Libre-TrainSim/blob/1e22e0eefe3d7e7dea8f21b695cc55e659ef4ccb/LICENSE) is GPLv3. Project notes identify game content as CC0, with separate [material](https://github.com/Libre-TrainSim/Libre-TrainSim/blob/1e22e0eefe3d7e7dea8f21b695cc55e659ef4ccb/src/Resources/Materials/LICENSE) and [JFR1 train](https://github.com/Libre-TrainSim/Libre-TrainSim/blob/1e22e0eefe3d7e7dea8f21b695cc55e659ef4ccb/src/Trains/JFR1/LICENSE) notices. Not all bundled media is CC0: [“Follow That Dream” by Luca Fraula](https://github.com/Libre-TrainSim/Libre-TrainSim/blob/1e22e0eefe3d7e7dea8f21b695cc55e659ef4ccb/src/Data/Misc/LICENSE_for_FollowThatDream) is CC BY 4.0. Bundled add-ons retain their own terms.

Use the repository and release links above rather than the old `.de` website links still present in the pinned README; the v0.8.1 notice reports a change to the project's website address.

## 3D-Racing-Game

[Firet’s 3D-Racing-Game](https://github.com/Firet/3d-racing-game) is a small circuit-racing project with vehicle controls, lap timing, a speed display, and a finish panel. It is a game implementation to inspect, not a claim of a production-scale racing simulator.

- **Obtain the project:** use the source repository. No official prepared build or release was established during this review.
- **Open the project:** the [README](https://github.com/Firet/3d-racing-game/blob/a2abbc38959ca77fe7017841ff2389d00ad45b36/README.md) specifies Godot 3.5.3-stable. The [vehicle script](https://github.com/Firet/3d-racing-game/blob/a2abbc38959ca77fe7017841ff2389d00ad45b36/Scripts/race_future.gd) extends `VehicleBody`; the [finish-line script](https://github.com/Firet/3d-racing-game/blob/a2abbc38959ca77fe7017841ff2389d00ad45b36/Scripts/finish_lap_area.gd) updates laps and reveals the finish panel.
- **Reuse limits:** a [GPLv3 license file](https://github.com/Firet/3d-racing-game/blob/a2abbc38959ca77fe7017841ff2389d00ad45b36/LICENSE) is present. ## Trampolines for Legs

[Eeyle’s Trampolines for Legs](https://github.com/Eeyle/Trampolines-for-Legs) is a small first-person 3D exploration/platforming game. Time a jump after landing to rebound, then combine higher jumps and wall jumps to traverse authored rooms. This is a playable personal game with levels and goal areas, not just an isolated movement controller or a claim of production-scale scope.

- **Play or obtain the project:** the [author’s page](https://eeyle.itch.io/trampolines-for-legs) marks it Released and lists an HTML5 game. That hosted game was not launched, and its correspondence to source revision `1fe210029cfe7700ba248dea0265ff6ae09e8441` is unverified.
- **Open the project:** this is **legacy Godot 3 Mono/C#**, not the non-Mono editor or a Godot 4 .NET project. The [README](https://github.com/Eeyle/Trampolines-for-Legs/blob/1fe210029cfe7700ba248dea0265ff6ae09e8441/README.md) identifies C#/Mono; the [C# project](https://github.com/Eeyle/Trampolines-for-Legs/blob/1fe210029cfe7700ba248dea0265ff6ae09e8441/Trampolines-for-Legs.csproj) targets .NET Framework v4.7 and references GodotSharp. Exact Godot minor/patch compatibility remains unresolved; committed `.mono` artifacts do not establish a reproducible build.
- **Inspect 3D implementation:** the [project](https://github.com/Eeyle/Trampolines-for-Legs/blob/1fe210029cfe7700ba248dea0265ff6ae09e8441/project.godot) opens the [tutorial scene](https://github.com/Eeyle/Trampolines-for-Legs/blob/1fe210029cfe7700ba248dea0265ff6ae09e8441/dungeons/tutorial/Tutorial.tscn). The [player scene](https://github.com/Eeyle/Trampolines-for-Legs/blob/1fe210029cfe7700ba248dea0265ff6ae09e8441/player/Player.tscn) supplies a `KinematicBody`, capsule collision, and camera; [jump](https://github.com/Eeyle/Trampolines-for-Legs/blob/1fe210029cfe7700ba248dea0265ff6ae09e8441/player/states/motion/air/JumpState.cs) and [landing](https://github.com/Eeyle/Trampolines-for-Legs/blob/1fe210029cfe7700ba248dea0265ff6ae09e8441/player/states/motion/ground/LandState.cs) states implement spatial movement and timed rebound.
- **Reuse limits:** the [root MIT license](https://github.com/Eeyle/Trampolines-for-Legs/blob/1fe210029cfe7700ba248dea0265ff6ae09e8441/LICENSE) credits Scott Armstrong; the publisher labels the code MIT. Separate asset provenance was not established, so this is not clearance to reuse every texture, model, or sound as MIT.

## Rapid Rescue

[Rapid Rescue](https://github.com/arran-nz/RapidRescue) is a small local-multiplayer river-tile strategy game. Insert and rotate tiles, navigate connected routes, and return stranded passengers; the first player to rescue five wins. **The rules and movement are planar on a grid, presented in a native Godot 3D world**, not free-roaming 3D action.

- **Choose a release or source:** the [README](https://github.com/arran-nz/RapidRescue/blob/6e3dbb73f4e666cb09ae31a0135ae4827027b12f/README.rst) links to [v0.2.1 Official Build](https://github.com/arran-nz/RapidRescue/releases/tag/v0.2.1), which lists Windows and Linux downloads. That release resolves to `49cdf2f358c139742e90b9ffdef3490e14b9fddf`, distinct from inspected source `6e3dbb73f4e666cb09ae31a0135ae4827027b12f`.
- **Open the project:** import [`MoveMaze/project.godot`](https://github.com/arran-nz/RapidRescue/blob/6e3dbb73f4e666cb09ae31a0135ae4827027b12f/MoveMaze/project.godot). Godot 3/GDScript is inferred from its project format and scene/API types; an exact minor/patch version is not declared in the inspected setup material.
- **Inspect 3D implementation:** [`Game_3D.tscn`](https://github.com/arran-nz/RapidRescue/blob/6e3dbb73f4e666cb09ae31a0135ae4827027b12f/MoveMaze/Game_3D.tscn) includes `Spatial` board/actor instances, a camera, and directional lighting. [Board logic](https://github.com/arran-nz/RapidRescue/blob/6e3dbb73f4e666cb09ae31a0135ae4827027b12f/MoveMaze/Scripts/Board/Board.gd) creates tile paths and computes reachability; [turn logic](https://github.com/arran-nz/RapidRescue/blob/6e3dbb73f4e666cb09ae31a0135ae4827027b12f/MoveMaze/Scripts/Game_Master.gd) manages insertion, movement, and scoring. Its `setup_from_autosave()` reports save/load as not operational and returns early; persistence is not a working feature of this inspected pin.
- **Reuse limits:** a [GPLv3 license file](https://github.com/arran-nz/RapidRescue/blob/6e3dbb73f4e666cb09ae31a0135ae4827027b12f/LICENSE) is present. A separate grant selecting only-versus-or-later and an exhaustive third-party asset-license inventory were not established.

## 3D Sledding

[3D Sledding](https://github.com/wi-photos/3D-Sledding) is a small endless downhill game: steer around obstacles, collect temporary speed boosts, and extend a distance score. Automatic forward motion is implemented in a real 3D world with gravity and collision. Jump code is commented out in the inspected revision, so jumping is not advertised as a working mechanic.

- **Play or obtain a build:** [release 1.2](https://github.com/wi-photos/3D-Sledding/releases/tag/1.2) lists Windows, Linux, and macOS downloads. Its tag resolves to inspected source `d47d06a7218db1588ff35f17ceb9a921c3ed0124`. This ties the tag to the source, not a verified binary build or successful play session.
- **Open the project:** the author reports Godot 3.2.2 with standard export templates on the [game’s itch page](https://wiphotos.itch.io/3d-sledding). The [project](https://github.com/wi-photos/3D-Sledding/blob/d47d06a7218db1588ff35f17ceb9a921c3ed0124/project.godot) uses GDScript/GLES2 and opens the main menu. The [README](https://github.com/wi-photos/3D-Sledding/blob/d47d06a7218db1588ff35f17ceb9a921c3ed0124/README.md) says source builds need their own Dreamlo keys for leaderboards. The inspected score code attempts an HTTP request after death with a placeholder, so disable or isolate those requests when evaluating locally rather than assuming an offline-only launch.
- **Inspect 3D implementation:** the [level scene](https://github.com/wi-photos/3D-Sledding/blob/d47d06a7218db1588ff35f17ceb9a921c3ed0124/level.tscn) contains `Spatial`, `KinematicBody`, camera, collision, and meshes. The [player script](https://github.com/wi-photos/3D-Sledding/blob/d47d06a7218db1588ff35f17ceb9a921c3ed0124/penguin.gd) connects `Vector3` velocity and `move_and_slide` to steering, gravity, boosts, and game-over behavior.
- **Reuse limits:** the [root code license](https://github.com/wi-photos/3D-Sledding/blob/d47d06a7218db1588ff35f17ceb9a921c3ed0124/LICENSE) is MIT. [Scene notices](https://github.com/wi-photos/3D-Sledding/blob/d47d06a7218db1588ff35f17ceb9a921c3ed0124/scenes/license.txt) list CC BY 3.0 and CC0 assets; [data notices](https://github.com/wi-photos/3D-Sledding/blob/d47d06a7218db1588ff35f17ceb9a921c3ed0124/data/license.txt) include CC BY-SA 3.0 music and CC0 files. Those asset notices remain separate from the code license.
