# Unity and Unreal game code and playable samples

Reviewed 2026-10-22 through official repository READMEs, project settings, selected gameplay code and author play/build pages. Five released games (including one source snapshot) and four engine demos/samples are described below, with code and content terms stated separately. No engine was installed and no game was built or playtested. Links use the reviewed default branches.

Choose a starting point by project scope:

- Released games: Daggerfall Unity, Fantasy Town Regional Manager, Catanks, Deliwar and Sudoku Challenge. Code/content terms are recorded individually; Sudoku Challenge provides a source snapshot without its editor project settings.
- Substantial permissively licensed demos/samples: Chop Chop and Epic Survival Game.
- Source-available samples with engine or author terms: FPS Sample and Action Roguelike.

## Daggerfall Unity — released classic RPG recreation

- **Repository / status:** [Interkarma/daggerfall-unity](https://github.com/Interkarma/daggerfall-unity), `master`. [README](https://github.com/Interkarma/daggerfall-unity/blob/master/README.md). A playable recreation of The Elder Scrolls II: Daggerfall, with first-person exploration, combat, quests, character progression and extensive mod support.
- **Stack / run:** C# / Unity; [ProjectVersion.txt](https://github.com/Interkarma/daggerfall-unity/blob/master/ProjectSettings/ProjectVersion.txt) records **2019.4.41f2**. The easiest route is the official [releases](https://github.com/Interkarma/daggerfall-unity/releases) for Windows, Linux and macOS. **A separate copy of DOS Daggerfall is required** for textures, models, audio and other original assets; the README links its free Steam release and explains pointing DFU to that installation. Source project startup scenes are recorded in [EditorBuildSettings](https://github.com/Interkarma/daggerfall-unity/blob/master/ProjectSettings/EditorBuildSettings.asset).
- **Useful source:** [QuestMachine.cs](https://github.com/Interkarma/daggerfall-unity/blob/master/Assets/Scripts/Game/Questing/QuestMachine.cs) loads quest text, registers actions, schedules quest execution and connects it to NPC interaction; [Quest.cs](https://github.com/Interkarma/daggerfall-unity/blob/master/Assets/Scripts/Game/Questing/Quest.cs) manages task state, completion and reputation. Useful for studying scripted quests in a substantial RPG.
- **License:** [Daggerfall Unity code is MIT](https://github.com/Interkarma/daggerfall-unity/blob/master/Assets/Licenses/Daggerfall%20Unity.txt). The original Daggerfall game data is a separate requirement and is not relicensed by the port.

## Fantasy Town Regional Manager — released turn-based town builder

- **Repository / status:** [CapsCollective/ozymandias](https://github.com/CapsCollective/ozymandias), `develop`. [README](https://github.com/CapsCollective/ozymandias/blob/develop/README.md). The repository name differs from the released game's name. A turn-based roguelite town builder with collectible building cards: attract adventurers, send them on quests, manage guild demands and survive escalating town events.
- **Stack / run:** C# / Unity **2021.3.1f1**, from [ProjectVersion.txt](https://github.com/CapsCollective/ozymandias/blob/develop/ProjectSettings/ProjectVersion.txt). The root is the Unity project; [build settings](https://github.com/CapsCollective/ozymandias/blob/develop/ProjectSettings/EditorBuildSettings.asset) identify `Assets/Scenes/Main.unity`. Author-supported playable releases are on [itch.io](https://capscollective.itch.io/ftrm) and [Steam](https://store.steampowered.com/app/1524530/Fantasy_Town_Regional_Manager/). README focuses on source study and purchasing the finished game, rather than providing a detailed contributor build guide.
- **Useful source:** [EventQueue.cs](https://github.com/CapsCollective/ozymandias/blob/develop/Assets/Scripts/Events/EventQueue.cs) chooses event pools from population, housing, stability, wealth and threats, then presents the outcomes as a newspaper. [GameManager.cs](https://github.com/CapsCollective/ozymandias/blob/develop/Assets/Scripts/Managers/GameManager.cs) ties the town systems and game lifecycle together. Useful for learning how systemic simulation creates narrative events.
- **License:** [Modified MIT](https://github.com/CapsCollective/ozymandias/blob/develop/LICENCE): source code can be reused; art, models, audio and writing remain proprietary. This is open game code with proprietary content.

## Chop Chop — discontinued Unity action-adventure demo

- **Repository / status:** [UnityTechnologies/open-project-1](https://github.com/UnityTechnologies/open-project-1), `main`. [README](https://github.com/UnityTechnologies/open-project-1/blob/main/README.md) explicitly says development ended in **December 2021**. A substantial community-built action-adventure demo with character combat, NPC dialogue, quest steps, inventory and cooking.
- **Stack / run:** C# / Unity **2020.3.17f1**, recorded in [ProjectVersion.txt](https://github.com/UnityTechnologies/open-project-1/blob/main/UOP1_Project/ProjectSettings/ProjectVersion.txt). Open `UOP1_Project`. The official [playing guide](https://github.com/UnityTechnologies/open-project-1/wiki/Playing-the-game) starts the game from `Assets/Scenes/Initialization.unity`, or offers TestingGround scenes for individual mechanics. [Release downloads](https://github.com/UnityTechnologies/open-project-1/releases) are linked from the README; the [build guide](https://github.com/UnityTechnologies/open-project-1/wiki/Building-the-game) explains building Addressables content before the player.
- **Useful source:** [QuestManagerSO.cs](https://github.com/UnityTechnologies/open-project-1/blob/main/UOP1_Project/Assets/Scripts/Quests/QuestManagerSO.cs) advances dialogue-driven quest steps and persists completed items; [InventoryManager.cs](https://github.com/UnityTechnologies/open-project-1/blob/main/UOP1_Project/Assets/Scripts/Inventory/InventoryManager.cs) handles event-channel requests to add, use and cook items. Practical examples of ScriptableObject data and event-driven gameplay composition.
- **License:** Repository [Apache 2.0](https://github.com/UnityTechnologies/open-project-1/blob/main/LICENSE); bundled third-party additions retain their notices.

## FPS Sample — legacy, functional Unity multiplayer shooter sample

- **Repository / status:** [Unity-Technologies/FPSSample](https://github.com/Unity-Technologies/FPSSample), `master`. [README](https://github.com/Unity-Technologies/FPSSample/blob/master/README.md) calls it a fully functional multiplayer FPS and explicitly says it is **no longer actively maintained**. The sample contains client/server and match flow.
- **Stack / run:** C# / Unity **2018.3.8f1**, HDRP, hybrid ECS patterns and Unity's contemporary network transport. Follow the README's matching-version setup and **clone with Git LFS**; a GitHub ZIP lacks required assets. The documented target is Windows client/server and Linux server. Open Level_00 via the Project Tools window for preview, then build asset bundles and the player to launch a local server/client from Quick Start. The README and [GettingStarted.md](https://github.com/Unity-Technologies/FPSSample/blob/master/Documentation/GettingStarted.md) are the operational entry points.
- **Useful source:** [GameModeAssault.cs](https://github.com/Unity-Technologies/FPSSample/blob/master/Assets/Scripts/Game/Systems/GameMode/Modes/GameModeAssault.cs) handles attacking/defending teams, capture points, timers and spawn selection; [GameModeSystemServer.cs](https://github.com/Unity-Technologies/FPSSample/blob/master/Assets/Scripts/Game/Systems/GameMode/GameModeSystemServer.cs) provides the server-side match framework. Useful historical material for networked shooter architecture.
- **License:** [Unity Companion License](https://github.com/Unity-Technologies/FPSSample/blob/master/LICENSE.md), with [the included terms](https://github.com/Unity-Technologies/FPSSample/blob/master/Assets/LICENSE.md) limiting reuse to Unity-dependent projects. Source-available Unity sample with engine-specific terms.

## Project Orion / Action Roguelike — ongoing Unreal gameplay sample

- **Repository / status:** [tomlooman/ActionRoguelike](https://github.com/tomlooman/ActionRoguelike), `master`. [README](https://github.com/tomlooman/ActionRoguelike/blob/master/README.md). A third-person co-op action-roguelike sample with magic attacks, teleport/dash, enemies, pickups, temporary effects and persistent player/world state. It is an actively extended teaching sample.
- **Stack / run:** C++ and Blueprint / Unreal Engine **5.8**, matching both README and [ActionRoguelike.uproject](https://github.com/tomlooman/ActionRoguelike/blob/master/ActionRoguelike.uproject). Open/build that project with its matching engine/toolchain; [DefaultEngine.ini](https://github.com/tomlooman/ActionRoguelike/blob/master/Config/DefaultEngine.ini) identifies TestLevel as the editor startup map and MainMenu_Entry as the game entry. The [author's documentation](https://tomlooman.com/unreal-engine-sample-game-action-roguelike/) explains systems and demonstrations. README links course-specific branches separately.
- **Useful source:** [RogueActionComponent.cpp](https://github.com/tomlooman/ActionRoguelike/blob/master/Source/ActionRoguelike/ActionSystem/RogueActionComponent.cpp) dispatches tagged actions and handles server requests/replication; [RogueGameModeBase.cpp](https://github.com/tomlooman/ActionRoguelike/blob/master/Source/ActionRoguelike/Core/RogueGameModeBase.cpp) integrates powerup placement, respawning and saved player state. Useful for connecting an ability system to multiplayer and a real game loop.
- **State / permission:** README explicitly calls `master` an experimental playground: some added systems are disabled by default and may not support multiplayer yet. It permits adapting project code/content for one's own Unreal game and identifies Paragon assets as **Unreal-only content**. This is a public-source educational sample with author-defined reuse permissions and separate Unreal asset terms.

## Epic Survival Game — legacy Unreal co-op survival sample

- **Repository / status:** [tomlooman/EpicSurvivalGame](https://github.com/tomlooman/EpicSurvivalGame), `master`. [README](https://github.com/tomlooman/EpicSurvivalGame/blob/master/README.md). Third-person co-op survival sample originally created for an Epic tutorial series: players fight AI, survive successive nights, score kills and lose the match when nobody remains alive. The author warns that its conventions date from 2015 and recommends Action Roguelike for newer patterns.
- **Stack / run:** C++ / Unreal; the current nested [SurvivalGame.uproject](https://github.com/tomlooman/EpicSurvivalGame/blob/master/SurvivalGame/SurvivalGame.uproject) associates with **UE 5.2** despite the project's UE4-era origins. Open/build that nested project. [DefaultEngine.ini](https://github.com/tomlooman/EpicSurvivalGame/blob/master/SurvivalGame/Config/DefaultEngine.ini) sets Landscape_Map for editor play and MainMenu_Entry for the game; the repository includes Content and Config alongside Source. Its gameplay code is a legacy learning reference.
- **Useful source:** [SCoopGameMode.cpp](https://github.com/tomlooman/EpicSurvivalGame/blob/master/SurvivalGame/Source/SurvivalGame/Private/World/SCoopGameMode.cpp) respawns players near living teammates, awards survival points after a night, brings spectators back and ends the match when all players die. Its compact match lifecycle makes a more approachable study than a full commercial shooter.
- **License:** Repository [MIT license](https://github.com/tomlooman/EpicSurvivalGame/blob/master/LICENSE); Unreal Engine itself is separately licensed.

## Catanks — released 3D tank-combat game

- **Repository:** [pennupgrade/catanks](https://github.com/pennupgrade/catanks), default branch **`sublevel1-merge`**; [README](https://github.com/pennupgrade/catanks/blob/sublevel1-merge/README.md). A student-made, released game about cat-piloted tanks fighting rodent enemies. It has a six-level campaign, an arcade-style classic mode, character abilities, achievements and multiple save slots.
- **Play / source setup:** The author's [itch.io page](https://pennupgrade.itch.io/catanks) provides Windows, Linux and macOS releases and marks the game Released; it also links Steam. Open the nested `Tanks` Unity project with **2022.3.62f2**, matching [ProjectVersion.txt](https://github.com/pennupgrade/catanks/blob/sublevel1-merge/Tanks/ProjectSettings/ProjectVersion.txt). [Build settings](https://github.com/pennupgrade/catanks/blob/sublevel1-merge/Tanks/ProjectSettings/EditorBuildSettings.asset) start with `Assets/Scenes/UI/TitleScreen.unity`. The README explains keeping `DISABLESTEAMWORKS` defined for ordinary itch/GitHub builds and removing it for Steam builds.
- **Useful source:** [Tank.cs](https://github.com/pennupgrade/catanks/blob/sublevel1-merge/Tanks/Assets/Scripts/Player/Tank.cs) connects input, tank movement/shooting state, damage, timed effects and character abilities. [GameManager.cs](https://github.com/pennupgrade/catanks/blob/sublevel1-merge/Tanks/Assets/Scripts/Managers/GameManager.cs) handles level transitions, saving completion, player death and respawning. A useful actual-game example of carrying combat mechanics through campaign progression.
- **License:** Contributor code is **MPL 2.0**, contributor art generally **CC BY-SA 4.0**; [REUSE.toml](https://github.com/pennupgrade/catanks/blob/sublevel1-merge/REUSE.toml) records per-file terms. The README separately identifies Unity/TMP components and proprietary UPGRADE branding.

## Deliwar — released delivery/combat game-jam project

- **Repository:** [deliteam/Deliwar](https://github.com/deliteam/Deliwar), `main`; [README](https://github.com/deliteam/Deliwar/blob/main/README.md). A Ludum Dare 53 side-scrolling action game in which collected boxes combine into the player formation, can be thrown at enemies, and must reach delivery points. It includes game-over and victory scenes, rather than only a mechanic test.
- **Play / source setup:** The author's [itch.io page](https://graphicedit.itch.io/deliwar) provides a browser version and links Windows builds. Open `LD53` with **Unity 2021.3.21f1**, confirmed by [ProjectVersion.txt](https://github.com/deliteam/Deliwar/blob/main/LD53/ProjectSettings/ProjectVersion.txt). [Build settings](https://github.com/deliteam/Deliwar/blob/main/LD53/ProjectSettings/EditorBuildSettings.asset) begin at `Assets/Scenes/Menu_Start.unity`. The optional Twitch integration is documented as Windows-only in the published versions; ordinary gameplay has a browser build.
- **Useful source:** [PlayerPackageController.cs](https://github.com/deliteam/Deliwar/blob/main/LD53/Assets/Code/Mono/PlayerPackageController.cs) handles box collection, count-based formation changes and throwing at enemies. [DeliveryPoint.cs](https://github.com/deliteam/Deliwar/blob/main/LD53/Assets/Code/DeliveryPoint.cs) converts a carried box into delivery progress; [TheEnd.cs](https://github.com/deliteam/Deliwar/blob/main/LD53/Assets/Code/TheEnd.cs) connects the 16 deliveries to the victory scene. Good for seeing how one resource participates in character shape, attacks and level objectives.
- **License:** Repository [MIT](https://github.com/deliteam/Deliwar/blob/main/LICENSE); the author page explicitly labels the code MIT and credits the team's original art/audio. Bundled libraries keep their own notices.

## Sudoku Challenge — released Android puzzle, useful source snapshot

- **Repository:** [michelbr84/SudokuChallenge](https://github.com/michelbr84/SudokuChallenge), `main`; [README](https://github.com/michelbr84/SudokuChallenge/blob/main/README.md). An Android Sudoku game with generated boards, adjustable difficulty, pencil notes, hints, timing, error feedback and completion UI. It is an actual small game, not an engine tutorial.
- **Play / source state:** The author publishes a [v1.0.0 release](https://github.com/michelbr84/SudokuChallenge/releases/tag/v1.0.0) containing [Sudoku.apk](https://github.com/michelbr84/SudokuChallenge/releases/download/v1.0.0/Sudoku.apk). Source includes `Assets/Scenes/MainMenu.unity`, `Assets/Scenes/SudokuPlay.unity`, prefabs, scripts and [Packages/manifest.json](https://github.com/michelbr84/SudokuChallenge/blob/main/Packages/manifest.json). **The reviewed tree has no `ProjectSettings` directory or recorded editor version**. This is a released game with a source snapshot, without a ready-to-open, version-pinned Unity project.
- **Useful source:** [Board.cs](https://github.com/michelbr84/SudokuChallenge/blob/main/Assets/Scripts/Board.cs) combines backtracking board completion, clue removal with a solution-count check, cell construction, undo/redo and completion feedback. [SudokuCell.cs](https://github.com/michelbr84/SudokuChallenge/blob/main/Assets/Scripts/SudokuCell.cs) connects values and pencil marks to the cell UI. A compact source-reading example for a puzzle generator plus the surrounding player interactions.
- **License:** Project [MIT](https://github.com/michelbr84/SudokuChallenge/blob/main/LICENSE), with bundled Unity/package components retaining their own licenses.
