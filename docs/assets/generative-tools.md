# Generative tools and services

Compare generation services by their job lifecycle, downloadable outputs, integration requirements, and usage terms. For research and commercial use, also check the [provider and model terms](api-terms.md).

| Resource and primary sources | Scope and integration constraints |
| --- | --- |
| [Runway API](https://docs.dev.runwayml.com/api/); [Runway SDK guide](https://docs.dev.runwayml.com/api-details/sdks/); [Standard terms (September 2026)](https://runway.com/terms-of-use); [Enterprise terms (June 2026)](https://runway.com/enterprise-terms) | Image/video generation returns managed tasks. SDK polling timeout or AbortSignal stops waiting, not remote generation; cancellation is separate. Standard terms permit commercial output use subject to compliance, allow provider training, and restrict developing similar or competing services. Enterprise data terms differ; benchmark-publication permission remains unresolved. |
| [fal Model APIs](https://fal.ai/docs/documentation/model-apis/inference/queue) | Queue-backed endpoints expose request IDs, polling and webhooks. Removing a queued request differs from canceling running work, which may still finish. Download expiring public media URLs promptly. Output schemas, model licenses and charges vary by endpoint; platform access does not establish commercial or research-use rights. |
| [Replicate Predictions](https://replicate.com/docs/topics/predictions/lifecycle) | Submit predictions and follow terminal state through polling or webhooks. [File acquisition and terminal accounting](generation-delivery.md#replicate-file-acquisition-and-terminal-accounting) remain separate, including early files and retained records whose outputs have expired. Deadline expiry before execution is distinct from cancellation after work starts, which can incur runtime charges. Check each model’s license and output terms independently; platform availability does not clear datasets, training use or commercial distribution. |
| [Meta AudioCraft](https://github.com/facebookresearch/audiocraft); [MusicGen-small pinned model card](https://huggingface.co/facebook/musicgen-small/blob/4c8334b02c6ec4e8664a91979669a501ec497792/README.md) | Local AudioGen and MusicGen research workflows support audio generation and training. Code is MIT, while released model weights use CC BY-NC 4.0; do not infer commercial model permission from the code license. The pinned MusicGen-small card recommends downstream risk evaluation. Output clearance remains separate. |
| [Material Maker](https://www.materialmaker.org/); [Material Maker repository](https://github.com/RodZill4/material-maker) | Build procedural node graphs and export PBR maps for engine materials; texture painting is described as experimental. Retain graph, seed and export settings for iteration. Repository files are MIT unless otherwise specified; shared materials need their own license review. No general remote automation API was verified. |
| [DeepMotion Animate 3D](https://www.deepmotion.com/animate-3d) | Convert authorized performer video into motion and export FBX, BVH, GLB or MP4 for cleanup and retargeting. Custom characters are supported; API and real-time SDK access are contact-sales offerings. Performer permissions, output-commercial rights, cancellation and retry billing require separate review. Generated contacts and occluded motion need inspection. |
| [Rokoko Vision](https://www.rokoko.com/products/vision) | Video capture feeds Rokoko Studio cleanup and FBX/BVH workflows. Export and custom retargeting depend on plan; the reviewed product page says finger tracking is unavailable and occlusion limits capture. No public API contract or output-commercial license was verified. Establish performer rights before uploading footage. |
| [Cascadeur](https://cascadeur.com/) | Desktop animation tools combine assisted posing, physics, rigging and retargeting with motion-file interchange. Review skeleton mapping and exported motion in the target engine. The vendor page supports the capabilities, not a tested quality result; headless automation and edition-specific commercial/export rights were not established. |
| [Cartesia Voice API](https://docs.cartesia.ai/get-started/overview) | REST and WebSocket speech workflows support streamed dialogue prototypes with Python and JavaScript integrations. The reviewed overview establishes interface availability, not measured latency or endpoint cancellation guarantees. Output rights, voice-cloning authorization and retry billing require separate verification before production use. |
| [Piper TTS](https://github.com/OHF-Voice/piper1-gpl) | Run neural speech synthesis locally through CLI, Python, C/C++ or a local HTTP server. Pin both engine and voice model. The current Open Home Foundation repository is GPL-3.0; individual voices have separate model licenses. Local execution avoids a per-request vendor contract but does not clear voice or distribution rights. |
| [Hyper3D Rodin API](https://docs.hyper3d.ai/en/get-started/quick-start); [Rodin API features](https://docs.hyper3d.ai/en/get-started/features); [API data retention](https://docs.hyper3d.ai/en/legal/data-retention-policy) | Text/image generation uses a download UUID and separate status subscription key. Require every job to finish successfully before fetching assets; archive within the documented seven-day active-system retention window. API policy excludes training/public posting of API data, with retention exceptions. Output-commercial rights and cancellation/refund behavior remain unverified. |
| [Adobe Firefly Custom Model Image API](https://developer.adobe.com/firefly-services/docs/firefly-api/guides/how-tos/cm-generate-image/); [Firefly API overview](https://developer.adobe.com/firefly-services/docs/firefly-api/) | Generate images using an authorized custom style or subject model. Preserve customModelId, model version and seeds; asynchronous submission returns job, status and cancellation URLs. OAuth, API credentials and custom-model access are separate requirements. The tutorial labels its sample non-production-ready: its model listing uses assetId while the full sample reads repo:assetId, and its status-based polling condition recognizes only succeeded/failed and has no deadline. Validate the actual schema and handle every documented terminal state before reuse. Cancellation availability is not a refund guarantee; output rights and artifact expiry need review. |
| [Roblox Cube Research Models](https://github.com/Roblox/cube); [Cube research license](https://raw.githubusercontent.com/Roblox/cube/main/LICENSE) | Local text-to-shape research code supports bounding-box conditioning and OBJ output. Geometry still needs topology, UV and material validation; extreme bounds can produce disconnected components. The reviewed research-only RAIL-MS license names v0.1 artifacts, so newer checkpoint scope needs explicit review. No commercial clearance or texture-generation claim is made. |
| [Hugging Face Diffusers](https://huggingface.co/docs/diffusers/using-diffusers/reusing_seeds); [Diffusers repository](https://github.com/huggingface/diffusers) | Python pipelines cover image, video and audio diffusion. Pin checkpoint revision, scheduler, dependencies and device; a seeded Generator helps repeatability without guaranteeing identical results across platforms or releases. Apache-2.0 covers the library, while model weights, inputs and generated-output terms remain separate. |
| [ComfyUI](https://github.com/Comfy-Org/ComfyUI) | Reusable node graphs drive asynchronous local inference with partial graph re-execution. Archive workflow JSON alongside custom-node code, checkpoints and seeds; JSON alone does not pin the environment. The engine is GPL-3.0, while nodes/models have separate terms. Partner nodes may call paid services with different cancellation and privacy behavior. |
| [Black Forest Labs FLUX.2 API](https://docs.bfl.ai/flux_2/flux2_image_editing) | FLUX.2 image editing supports multiple ordered reference images and asynchronous polling. Distinguish the pinned flux-2-pro endpoint from changing preview variants; fetch result.sample only after Ready. Technical documentation does not establish output licensing, download expiry or retry/refund behavior. API and playground reference limits differ. |
| [Human Motion Diffusion Model (MDM)](https://github.com/GuyTevet/motion-diffusion-model) | Research code samples human motion from text or action conditions. Preserve generated arrays before retargeting, then inspect joint mapping, root motion, timing and contacts. MIT covers code; body models such as SMPL/SMPL-X and datasets have separate licenses. Checkpoint and output-commercial rights are not established by the code license. |
| [Luma Agents API](https://docs.agents.lumalabs.ai/); [Legacy migration and output contract](https://docs.agents.lumalabs.ai/guides/videos/migration/); [API-specific terms (April 2026)](https://lumalabs.ai/legal/api-terms-of-use) | Ray 3.2 Agents requests differ from legacy Dream Machine schemas and model IDs. Output URLs expire after one hour and can be refreshed. April 2026 API terms prohibit AI/ML training, fine-tuning or evaluation datasets and constrain benchmark publication, with a specific internal integration-evaluation exception for benchmarking only. This exception does not apply to the separate dataset prohibition. API inputs/outputs are not used for provider training. |
