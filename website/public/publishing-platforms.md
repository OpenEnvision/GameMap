# Find games and publish your own

These platforms connect a finished game with players. They are discovery and distribution resources, separate from GameMap's creator-evidenced AI game examples. Official entry points checked on **October 20, 2026**.

| Platform | Find games | Publish or prepare a release | What to expect |
| --- | --- | --- | --- |
| Steam | [Browse Steam](https://store.steampowered.com/) | [Steamworks](https://partner.steamgames.com/) · [Getting started](https://partner.steamgames.com/doc/gettingstarted) | Desktop storefront; partner onboarding, store pages, builds, testing, and release review. |
| itch.io | [Browse itch.io](https://itch.io/games) | [Developer overview](https://itch.io/developers) · [Create a project page](https://itch.io/docs/creators/getting-started) | Creator-managed pages for browser builds, downloads, and demos. |
| Epic Games Store | [Browse Epic Games Store](https://store.epicgames.com/en-US/) | [Distribution overview](https://store.epicgames.com/en-US/distribution) · [Developer Portal documentation](https://dev.epicgames.com/docs/dev-portal) | Store publishing tools for pages, builds, and updates; independent of the engine used. |
| GOG | [Browse GOG](https://www.gog.com/en/games) | [Submit a game](https://www.gog.com/submit-your-game) | Curated DRM-free desktop catalog; a submission is not automatic publication. |
| CrazyGames | [Play browser games](https://www.crazygames.com/) | [Developer portal](https://developer.crazygames.com/) · [Publishing documentation](https://docs.crazygames.com/) | Web builds with technical requirements, testing, QA review, and staged launches. |

## Steam release watch: SlopArena

Checked on **October 20, 2026**, [SlopArena's Steam page](https://store.steampowered.com/app/5324910/) shows **Coming Soon** and **Request Access** for its playtest. It offers a concrete example of a store description, AI-content disclosure, and playtest entry before general release.

The author's [Getting set up instructions](https://github.com/Binoui/SLOPArena#getting-set-up) require Unity **6000.0.78f1**, a separately installed **Animancer** package, and paid art omitted from Git. A fresh clone cannot open the full Unity game; the code-only simulation and tools are a separate route. This is a publishing observation, outside the complete-source playable-game directory. This review read the public pages without installing the project.

## Read the access links carefully

- **Browser play** opens a running web build. A store page, trailer, or Coming Soon listing is not a browser demo.
- **Game download** is a prepared build for specific systems. A GitHub source archive usually needs dependencies and a local build; it is not the same as an executable release.
- **Project source** should contain the complete game implementation and its required assets or clear acquisition instructions. A store presence, a DRM-free release, or browser-delivered scripts alone does not establish that scope.
- **AI development evidence** comes from the creator's account of how the project was built. Distribution on any of these platforms does not establish AI authorship.

Check the current official submission requirements before publishing. Product availability, commercial terms, regional access, and supported systems belong to each platform and game; this guide does not freeze prices, fees, or revenue shares.
